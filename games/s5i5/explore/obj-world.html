`World` —— 这一局一帧的全部状态。字段就是这一局的对象。

每个字段为什么删不掉，写在 `analysis/<字段>.txt`（区分检验的见证是哪两帧）。

    board   盘面（一关之内不动）：面板 / 图例 / 菱形 / 枢纽 / 钉死的墙
    bars    条
    walls   推得动的墙（刚体长方形）
    spent   计费行已烧几格

`unsure`：这一帧**读得成**一个世界，但有一位信息帧上说不清——
  'split'  同色两根条首尾相顶，分界在哪帧上看不出（取了一种，另一种也对得上这一帧）
  'wall'   同色墙拆成长方形的拆法不止一种
它不是世界的一部分，是「这一帧的读法」的一部分；规则在它非空时对依赖那一位的判断闭嘴。

"""`World` —— 这一局一帧的全部状态。字段就是这一局的对象。

每个字段为什么删不掉，写在 `analysis/<字段>.txt`（区分检验的见证是哪两帧）。

    board   盘面（一关之内不动）：面板 / 图例 / 菱形 / 枢纽 / 钉死的墙
    bars    条
    walls   推得动的墙（刚体长方形）

`unsure`：这一帧**读得成**一个世界，但有一位信息帧上说不清——
  'split'  同色两根条首尾相顶，分界在哪帧上看不出（取了一种，另一种也对得上这一帧）

它不是世界的一部分，是「这一帧的读法」的一部分；规则在它非空时对依赖那一位的判断闭嘴。
"""
from __future__ import annotations

from dataclasses import dataclass

from .board.board import Board
from .piece.bar import Bar
from .piece.wall import Wall


@dataclass(frozen=True)
class World:
    board: Board
    bars: tuple[Bar, ...]
    walls: tuple[Wall, ...]
    spent: int                       # 计费行已烧几格（0..64）
    unsure: frozenset = frozenset()
