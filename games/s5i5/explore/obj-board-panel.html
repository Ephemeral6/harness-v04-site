`Panel` —— 面板：一个色 2 描边的框，里面两颗同色图标，中间一道色 3 分隔线。

**人话**：面板管一种颜色的条。点分隔线前面那颗（左 / 上）是「缩」，
点后面那颗（右 / 下）是「伸」。被管的颜色 = 图标的颜色。

记的是：颜色、框、两颗图标的中心格。只记这些的理由（判据 1）：
点击落点在语料里**全部**落在图标中心格上（2 393 / 2 393 次，`analysis/panel.txt`），
框的其余几何没有任何规则读。框本身要留着：点在框里、不在图标上的那一类点击，
规则要能认出来（它们在语料里 0 次，但论域要写得出来）。

from __future__ import annotations

from dataclasses import dataclass


@dataclass(frozen=True)
class Panel:

    grow_at: tuple[int, int]        # 「伸」图标中心格
