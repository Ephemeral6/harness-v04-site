作废.wall_onto_target_refuses

读数：开口 4 行（去重 1）· 判对 4 · 判错 0 · 读不清 0 · 闭嘴 2614

它说什么：点「伸」时，被带着走的墙原来不压靶、落点压上了靶（菱形中心或四个点之一），整步作废。

什么时候不管：只管模型把作废记在这一条名下的步。

明确不主张：**两种读法分不开，这一条只取了其中一种**：语料里 4 次作废全是「伸 + 墙沿自己长轴被顶」，15 次照走全是「缩 + 墙横着被拖」——「伸而不是缩」和「沿长轴而不是横着」完全同步，一次都没分开过。能分开它们的实验：伸的时候把一面墙**横着**顶上靶（或缩的时候沿长轴拖上靶），看作不作废。见 analysis/gaps.txt。

点「伸」时，被带着走的墙原来不压靶、落点压上了靶，整步作废。

**两种读法语料分不开，这里只取了其中一种**（「伸而不是缩」；另一种是「沿墙的长轴而不是横着」）。

import Obj.World

namespace Game

def wallOntoTarget (bd : Board) (grow : Bool) (ws : List (Wall × Option Dir)) : Bool :=
  grow && ws.any (fun
    | (w, some d) => meetsAny (w.shift d).rect bd.targets && !meetsAny w.rect bd.targets
    | _ => false)

end Game

def refuses(m) -> bool:
    if m.s <= 0:
        return False
    tc = target_cells(m.w.board)
    return any(wall_cells(m.nw[j]) & tc and not (wall_cells(m.w.walls[j]) & tc) for j in m.movedw)


def scope_(w, action, ctx=None):
    return refusal_scope(w, action, ME, ctx)


def assert_(w, action, nw, ctx=None) -> bool:
    return unchanged(w, nw)
