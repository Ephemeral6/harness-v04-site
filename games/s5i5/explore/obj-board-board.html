board/board

`Board` —— 盘面：一关之内一格都不动的全部东西。

**人话**：这一关长什么样——面板在哪、图例在哪、靶在哪、钉死的墙在哪、枢纽在哪。
你点来点去，它都不变；换关时整个换掉。

**第 1 轮简化合并出来的**（卡 03，`analysis/record.txt`）：原来这五样是 `World` 的五个字段，
分离表对它们五个全报「分不开」，而且**同组取值数恒为 1**——它们在整批语料里只随关一起变，
从没有一个单独变过。按判据「同生共死 ⇒ 是一样东西的几个写法」合成一个。

合成一个的另一个好处在形式化那边：`Board` 不是状态的一部分，`step` 碰不到它，
「走一步盘面不会变」于是**表示不出反例**。

"""`Board` —— 盘面：一关之内一格都不动的全部东西。

**人话**：这一关长什么样——面板在哪、图例在哪、靶在哪、钉死的墙在哪、枢纽在哪。
你点来点去，它都不变；换关时整个换掉。

**第 1 轮简化合并出来的**（卡 03，`analysis/record.txt`）：原来这五样是 `World` 的五个字段，
分离表对它们五个全报「分不开」，而且**同组取值数恒为 1**——它们在整批语料里只随关一起变，
从没有一个单独变过。按判据「同生共死 ⇒ 是一样东西的几个写法」合成一个。

合成一个的另一个好处在形式化那边：`Board` 不是状态的一部分，`step` 碰不到它，
「走一步盘面不会变」于是**表示不出反例**。
"""
from __future__ import annotations

from dataclasses import dataclass

from .diamond import Diamond
from .hub import Hub
from .legend import Legend
from .panel import Panel


@dataclass(frozen=True)
class Board:
    panels: tuple[Panel, ...]
    legends: tuple[Legend, ...]
    diamonds: tuple[Diamond, ...]
    hubs: tuple[Hub, ...]
    fixed: frozenset             # 色 15 的格子：推不动的死物
