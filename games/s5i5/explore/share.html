怎么给别人看

直接发：整个 web/dist/ 文件夹拷走或压成 zip。每一页都自包含（样式、脚本、数据都在页面里），双击就能看，不联网、不装东西。

局域网里给别人看：cd web/dist && python -m http.server 8000，第一次弹防火墙只允许专用网络。

重新生成（顺序不能换，读数只有一个来源）：

python run_rules.py --reverse     读数 + 反向测试
python lean2/export_replay.py      观测只存一份
python lean2/export_levels.py      每一关一条定理
python lean2/reconcile.py          Python 与 Lean 在同一条路上对账
python lean2/verify.py             编译 + 核判准 → lean2/readings.json（读不到就不出页面）
python web/export.py               页面要摆的每个数
python web/pages.py                生成 dist/
python web/check_no_logic.py       前端有没有偷偷自己算世界
