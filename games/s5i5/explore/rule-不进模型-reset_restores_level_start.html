不进模型.reset_restores_level_start

读数：开口 16 行（去重 15）· 判对 16 · 判错 0 · 读不清 0 · 闭嘴 2602

它说什么：RESET 之后，条、墙、盘面都回到这一关第一帧的样子，计费行退回 0。

什么时候不管：只管关内的 RESET（段首那一下 RESET 是开新一局，它回到第 0 关开局，同样算）。

明确不主张：不主张 RESET 会不会换关（语料里从没换过）。

  • 没有专门对准它的

形式化里：不进模型——「这一关开局长什么样」是历史不是局面的函数；写成 Proof/Levels 里的明写假设，每段从开局起核

"""RESET 把局面放回这一关的开局（计费退回 0）。"""
from __future__ import annotations

from rule._common import pieces_equal

CLAIM = "RESET 之后，条、墙、盘面都回到这一关第一帧的样子，计费行退回 0。"
SCOPE_NOTE = "只管关内的 RESET（段首那一下 RESET 是开新一局，它回到第 0 关开局，同样算）。"
NOT_CLAIMED = "不主张 RESET 会不会换关（语料里从没换过）。"
WHY_NOT_IN_MODEL = ("「这一关开局长什么样」不是当前局面的函数，是历史，一帧上读不出来。"
                    "形式化里它是一条明写的假设：每一关的尾段从开局起逐帧核对，假设错了第一帧就红。")
HISTORY = ["v1 起点册子 level_start_is_fixed 的 RESET 那一半。"]
EVIDENCE = [2506, 2528]


def scope_(w, action, ctx=None):
    if ctx is None or ctx.get("mark") != "reset":
        return "不是 RESET"
    if ctx.get("start") is None:
        return "这一段里还没见过这一关的开局帧"
    return None


def assert_(w, action, nw, ctx=None) -> bool:
    st = ctx["start"]
    return pieces_equal(st, nw) and nw.board == st.board and nw.spent == 0
