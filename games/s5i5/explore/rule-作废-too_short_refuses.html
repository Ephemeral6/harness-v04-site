它说什么：点「缩」时，那一色只要有一根条缩完身体不足 2 条，整步作废——同色能缩的也不缩。

def refuses(w, K: int, s: int) -> bool:
    return s < 0 and any(b.color == K and b.length + s < 2 for b in w.bars)
