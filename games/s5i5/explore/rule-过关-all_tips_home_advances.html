它说什么：一步之后所有尖都在靶心上、每个靶心上都有尖（两个集合相等），这一步就换关；不相等就绝不换关。

什么时候不管：看全部关内步与换关步（RESET 不看）。模型对这一步不说话、或这一帧读法说不清时闭嘴。换关步的下一帧是下一关的盘，所以这一条**只用模型算出来的下一帧**，不看观测的下一帧。

明确不主张：不主张换关之后是哪一张盘（那是 不进模型/reset_restores_level_start 同一类的历史）。

def goal(w) -> bool:
    ts = {tip_cell(b) for b in w.bars if b.tip}
    return ts == centers(w.board)


def scope_(w, action, ctx=None):
    if ctx is None or ctx.get("mark") not in ("ok", "levelup"):
        return "RESET 或读不成的帧"
    out = predict_cached(w, action)
    if out.world is None:
        return "模型不说话"
    why = unreadable_input(w, out)
    if why:
        return why
    return None


def assert_(w, action, nw, ctx=None) -> bool:
    out = predict_cached(w, action)
    return goal(out.world) == (ctx["mark"] == "levelup")
