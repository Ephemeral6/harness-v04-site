`Board` —— **版面**：这一关的圈在哪、要交什么。一关之内一位都不变。

卡 06 把 `rings` 与 `samples` 两个字段合成这一个（`analysis/record.txt` 第 3 轮）。两个信号同时成立：

  · 分离表：两者都 0 见证，而且只在换关时一起变（同生共死于「关」）；
  · 规则那一侧：读它们的 4 处（过关判定 ×2、换关那一步、撤销 / 重来的比较）**每一处都是两个一起读**，
    从没有一条规则只读其中一个。

合起来之后它和 Lean 那边的 `Board`（`step` 碰不到的那一半）是同一个东西：
「走一步版面不变」在 Lean 里表示不出来，在 Python 里也只剩一个字段可比。

为什么删不掉它（analysis/board.txt）

board —— 版面：圈（Ring，9×9 八边形框的左上角）与样板（Sample，件的级 / 会动的东西的种类）

1. 它记的是什么
   这一关哪几个位置是圈、要往圈里交什么。一关之内一位都不变（Lean 那边住在 Board，step 碰不到）。
   卡 06 由 rings + samples 两个字段合成（record.txt 第 3 轮）。

2. 哪几条规则读它
   levelup_iff_covered_after_step、still_uncovered_while_playing、levelup_starts_fresh、undo_restores_before_last_click、
   reset_refills_budget、click_top_band_inert。每一条都是 rings 与 samples 一起读（合并的第二个信号）。

3. 抹成常量之后哪几条判决变（真跑，ablation.json per_rule）
   levelup_starts_fresh 39、levelup_iff_covered_after_step 22、undo_restores 87、reset_refills_budget 20；合计 168。
   （合并前：rings 134、samples 281 —— analysis/history/analysis_2/ablation.json。）

4. 分离表 vs 上面两句 —— **对不上，这是这一位的欠账**
   分离表：分不开（0 见证）。点名 6 条、消融 168 处——规则在读它，而语料里找不到「只差版面」的一对世界：
   版面只在换关时变，而换关时件、会动的东西、预算全都跟着换了。
   这是「这批语料分不开它」（卡 03 那三种里的 ③），不是「没人读」。
   能分开它的实验：在两关摆出一模一样的件和会动的东西，看过关判定是不是跟着版面走——语料里 0 次，要上世界才做得了。
   **所以这一位的「抹掉它哪一对局面分不开」只有消融这一侧的见证，没有分离表那一侧的见证。**
   消融见证（runs/_wb-su15/board_witness.py 实测，认证段每个过关步把版面换成语料第一帧的版面）：
     第 821 步（第 0 关）  真版面 won / 换版面 won   —— 第 0 关本来就是那一块版面，不变
     第 833 / 849 / 861 / 878 / 884 步（第 1/2/3/5/6 关）  真版面 won / 换版面 ok —— 判决翻了
     第 867 / 894 / 904 步  两边都是 na（会动的东西那一相说不出），这一步分不出

# Board —— 版面：圈与样板，一关之内不变

对应 Python `objects/board/board.py`。**它不是状态 `World` 的字段**：`step` 拿它当参数读，
却没有任何一支能返回一个新的 `Board` —— 于是「走一步版面不变」不用证，它**表示不出来**。
（Python 那边 `World.board` 是一个字段，因为帧上读得出来；两边的差别就在这一句。）
-/
