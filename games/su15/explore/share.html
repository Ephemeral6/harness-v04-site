怎么给别人看

在自己电脑上看、发出去、重新生成。
这是个什么游戏回放对象规则形式化怎么给别人看

在自己电脑上看

双击 web/dist/index.html。每一页的样式、脚本、数据都内联在 HTML 里，不需要起服务、不需要联网。

发给别人

把整个 dist/ 文件夹拷走或压成 zip 发出去（页面之间是相对路径，只拷一页打不开）。 同一个局域网：cd dist && python -m http.server 8000。

重新生成（顺序不能换）

python corpus.py                  卡 00：切段、对账
python run_rules.py --reverse     读数 + 反向测试，全绿才往下走
python lean2/export_replay.py     观测那一份，下面两份都从它切
python lean2/export_corpus.py
python lean2/export_levels.py
python lean2/verify.py            编译 + 机械核判准，落盘 readings.json
python web/export.py              把页面要摆的每个数算好（读上一步的落盘）
python web/pages.py
python web/bundle.py
python web/check_no_logic.py
