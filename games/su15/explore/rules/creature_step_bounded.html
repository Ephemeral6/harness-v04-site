身份：推论（Derived/StepBounded.lean 的 chase_bounded）

它说什么

棋盘点击之后，每一只**不在追刚落下那一件**的会动的东西，都能在下一帧找到同种的一只，行、列各自挪了不超过 4 格。

它明确不主张什么

不主张追新件的那些（它们会被甩出十几格：甩飞，说不出）；不主张同种只数变了的那几步（两只并成一只高一级的）；不主张挪到哪一格（归 creature_chases_target）。

判错归因

1甩飞：追新件的那只一步挪了 >4 格（没压上新件也会甩，这一版说不出触发条件）
3几只一起挪：互相挡 / 抢同一件（这一版只描述各走各的）

# StepBounded —— **推论**：会动的东西一步最多挪 4 格（行、列各自）

对应 Python `rule/会动的东西/creature_step_bounded.py`。它在 Python 那一侧是一条要逐帧核的规则（上界），
在这里是 `Rule/Creature/Chase.lean` 的**推论**：`chase` 最多走 4 小步，每小步每轴挪 −1 / 0 / +1。
所以它不是一条独立的规则——它是「追」这个定义自己带出来的。

注意分量：这条定理说的是**模型**里的追。现实里「追新件的那只」会被甩出十几格（甩飞），
那一支模型说不出话（`Step.lean` 返回 `na`）；Python 那一条的论域也把它们排除在外。两边口径一致。
-/

import Rule.Creature.Chase

namespace Game

theorem sgn_bounds (d : Int) : sgn d ≤ 1 ∧ -1 ≤ sgn d := by
  unfold sgn
  split
  · omega
  · split <;> omega

theorem chaseN_bounded (n : Nat) : ∀ (c : Creature) (t : Piece),
    (chaseN n c t).row - c.row ≤ n ∧ c.row - (chaseN n c t).row ≤ n ∧
    (chaseN n c t).col - c.col ≤ n ∧ c.col - (chaseN n c t).col ≤ n := by
  induction n with
  | zero => intro c t; simp [chaseN]
  | succ n ih =>
    intro c t
    simp only [chaseN]
    split
    · omega
    · split
      · omega
      · obtain ⟨h1, h2, h3, h4⟩ := ih { c with row := c.row + sgn ((pCentre t).1 - (cCentre c).1),
                                                col := c.col + sgn ((pCentre t).2 - (cCentre c).2) } t
        have s1 := sgn_bounds ((pCentre t).1 - (cCentre c).1)
        have s2 := sgn_bounds ((pCentre t).2 - (cCentre c).2)
        simp only at h1 h2 h3 h4
        refine ⟨?_, ?_, ?_, ?_⟩ <;> push_cast <;> omega

/-- **一步最多挪 4 格**（行、列各自）——对任何一只、任何目标都成立，不枚举。 -/
theorem chase_bounded (c : Creature) (t : Piece) :
    (chase c t).row - c.row ≤ 4 ∧ c.row - (chase c t).row ≤ 4 ∧
    (chase c t).col - c.col ≤ 4 ∧ c.col - (chase c t).col ≤ 4 :=
  chaseN_bounded 4 c t
