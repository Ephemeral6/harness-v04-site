它说什么

会动的东西挪完压在一件**不是刚落下的**件上：那件不见了，换成低一级的一件，左上角 = 原左上角 + round(10 · 从咬它那只的重心指向件心的单位向量)，夹进棋盘；1 级件被咬就没了。

它明确不主张什么

不主张刚落下的新件会怎样（它咬不动：甩飞，说不出）；不主张两只咬同一件（语料里没分出来）。

判错归因

2单只追旧件，落点差一两格（没归因到上面几类）
11几只一起挪：互相挡 / 抢同一件（这一版只描述各走各的）
1甩飞：追新件的那只一步挪了 >4 格（没压上新件也会甩，这一版说不出触发条件）

# Bite —— 挪完压在旧件上：那件降一级，沿「咬它的那只 → 件心」甩开 10 格

对应 Python `rule/会动的东西/bite_demotes_and_flings.py`（算法在 `derive/creature/bite.py`）。**只有定义。**
round(10·v/√L2) 不开方：找整数 r 使 (2r−1)·√L2 ≤ 20v < (2r+1)·√L2，两边按符号平方比较。
-/

import Rule.Creature.Chase

namespace Game

/-- a·√l2 ≤ b（l2 > 0）。 -/
def leMulSqrt (a l2 b : Int) : Bool :=
  if a ≤ 0 ∧ 0 ≤ b then true
  else if 0 < a ∧ b < 0 then false
  else if 0 ≤ a then decide (a * a * l2 ≤ b * b)
  else decide (b * b ≤ a * a * l2)

def roundRatio (v l2 : Int) : Int :=
  match (List.range 21).find? (fun (i : Nat) =>
      leMulSqrt (2 * ((i : Int) - 10) - 1) l2 (20 * v) && !(leMulSqrt (2 * ((i : Int) - 10) + 1) l2 (20 * v))) with
  | some i => (i : Int) - 10
  | none => 0

/-- 被 `c` 咬了之后的那一件；1 级件被咬就没了（`none`）。 -/
def bitten (p : Piece) (c : Creature) : Option Piece :=
  if p.tier ≤ 1 then none
  else
    let dy := (pCentre p).1 - (cCentre c).1
    let dx := (pCentre p).2 - (cCentre c).2
    let l2 := dy * dy + dx * dx
    let sr := if l2 = 0 then 0 else roundRatio dy l2
    let sc := if l2 = 0 then 0 else roundRatio dx l2
    let s : Int := (side (p.tier - 1) : Int)
    some ⟨p.tier - 1, min (max (p.row + sr) 10) (63 - s + 1), min (max (p.col + sc) 0) (64 - s)⟩

end Game
