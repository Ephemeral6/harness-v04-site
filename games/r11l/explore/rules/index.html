明写的缺口（6 条）—— 摆在最上面，不藏

  • 「不可做」只有一把钥匙（墨用光了、颜色又不对）；技能要求至少两把理由不同的，第二把（挡住了）没写
  • 配对的「颜色集合」那一半这批语料考不动：反向测试把配对改成不看颜色，判错 0——罐子从没落在配不上的靶心上
  • 看不见的底色按「不挡路」算（明写的假设）：Python 倚仗它 32 步、被驳倒 0 次；整关拼盘之后仍看不见的格同样按这一条
  • RESET 不进模型：「放回第 0 关开局」在这批语料上被驳倒的机会只有 1 次（没被驳倒不构成证明）
  • 预算 60 下是外推（每关最多见到第 23 下），竖条见底会怎样语料 0 次
  • 点在两颗菱形重叠处：Lean 取 anchors 里第一颗、Python 取排序后第一颗，语料 0 次，两边在这一处可能不同

一步怎么走

**这一组管：点一下之后，选中换给谁、哪颗菱形挪到哪。**

click_moves没点在菱形上、挪过去不踩禁地：选中那颗菱形挪到点击格（仍是选中），它那一组的锚点换成新的一套；**别的每一组的锚点原样**。挪过去压到别的东西不算挡路。定义 · 开口 89 · 判错 0 click_rejected没点在菱形上，而挪过去之后菱形 13 格踩到硬墙（2）、或罐子 21 格踩到硬墙 / 软地（10）：这一下被驳回——选中不变，所有菱形原地不动。定义 · 开口 6 · 判错 0 click_selects点在某颗菱形的 13 格里：选中换到那一颗；所有菱形原地不动。定义 · 开口 78 · 判错 0
世界怎么回应

**这一组管：挪完之后，世界自己起了什么变化**——罐子的墨、漆块、竖条、底色。

absorb这一步挪动之后罐子中心正好落在某块漆块的中心上 ⟺ 取墨：漆块 21 格里有墨（非 0）的格按同一偏移**盖**到罐子上（原来的颜色也被盖掉），没墨的格罐子原样，那块漆块从盘上消失。别的情形（选中、驳回、挪到别处）：每个罐子的墨原样，漆块一块不少、一格不变。定义 · 开口 173 · 判错 0 bar同一关里每点一下（选中、挪动、被驳回都算），`spent` 加 1；进入新一关的那一步之后 `spent` = 0（竖条满格）。通关那一步不算换关，照常加一。定义 · 开口 183 · 判错 0 terrain_static同一关里，前后两帧都看得见底色的每一格，颜色相同。推论 · 开口 173 · 判错 0
什么算赢

**这一组管：靶环什么时候锁上、这一关什么时候算过。**

level_clear这一步之后，**每一组**的罐子中心都压在一个锁上的靶心上 ⟺ 这一步过关（上游 level 加一：换到下一关，或最后一关的 WIN）。定义 · 开口 183 · 判错 0 lock这一步挪动之后，罐子中心落在某个没锁的靶心上，且罐子环上（20 格，不含核）的颜色集合等于那个靶环四条臂的颜色集合（取墨在先）：那个靶环锁上（臂色消失）；别的靶环原样。没挪动（选中、驳回）或没落在配得上的靶心上：靶环全部原样。定义 · 开口 173 · 判错 0
