明写的缺口（6 条）—— 摆在最上面，不藏

  • 「不可做」只有一把钥匙（墨用光了、颜色又不对）；技能要求至少两把理由不同的，第二把（挡住了）没写
  • 配对的「颜色集合」那一半这批语料考不动：反向测试把配对改成不看颜色，判错 0——罐子从没落在配不上的靶心上
  • 看不见的底色按「不挡路」算（明写的假设）：Python 倚仗它 32 步、被驳倒 0 次；整关拼盘之后仍看不见的格同样按这一条
  • RESET 不进模型：「放回第 0 关开局」在这批语料上被驳倒的机会只有 1 次（没被驳倒不构成证明）
  • 预算 60 下是外推（每关最多见到第 23 下），竖条见底会怎样语料 0 次
  • 点在两颗菱形重叠处：Lean 取 anchors 里第一颗、Python 取排序后第一颗，语料 0 次，两边在这一处可能不同

盘上有几组东西，每组是一个「罐子」加两三颗「菱形」，罐子和它的每颗菱形之间连着虚线。 罐子自己不能点——它永远待在它那几颗菱形的正中间（下取整的质心）。

你点一颗菱形，就选中它；再点一块空地，选中的那颗就挪过去，罐子随之挪到新的正中间。

把每个罐子都挪到一个和它「颜色对得上」的靶环中心，靶环就锁上；全部锁上，这一关就过了。 后面几关罐子一开始是空的，得先让罐子落到一块漆块上，把墨取进来，凑出靶环要的那几种颜色。

点一块空地：选中的菱形挪过去，罐子跟着挪到新的正中间，虚线重画（seq 104，在回放里看）

你能做的只有一件事：点一格

  • 点在一颗菱形上——选中换到它，谁也不挪。（例：seq 105）
  • 点在别处——选中的那颗菱形挪到那一格；它那一组的罐子跟到新的正中间。
  • 每点一下，左边那根竖条就短一截（这一关的预算；它是「点了几下」的显示）。

挡路的只有底色，而且两种禁地后果不同

硬墙菱形站不上，罐子也压不上。
软地菱形站得上，罐子压不上。挪一颗菱形，要看它自己落在哪，也要看罐子跟过去落在哪。
别的东西压到别的菱形、漆块、靶环都不算挡路——只有底色说了算。

踩了禁地，这一下被驳回：谁也不挪，只是竖条照样短一截。

一次被驳回的点击：罐子要跟到的地方压着禁地，所以谁也没挪（seq 15，在回放里看）
