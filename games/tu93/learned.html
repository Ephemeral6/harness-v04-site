它是怎么学出来的

agent 边玩边把看到的规律写成可检验的代码：每条都对接下来的每一步自动判对错，一被画面驳倒就改写。它一共写过 17 条说法，前后改了 38 版；通关之后，这些说法合并成首页的规则。

每条规则的来历

  • 往有桥的方向走一格，记号转过去；没桥就不动
    由这些早期说法合并而来：bridge_gate、move_shift、mark_faces
  • 哨兵永远站在原地、朝着原来那边
    由这些早期说法合并而来：foe_walks
  • 玩家真走了一步，每只巡逻就沿桥走一步
    由这些早期说法合并而来：patrol_steps、patrol_turns
  • 追兵被惊醒后，每步沿最短路扑向玩家原来那格
    由这些早期说法合并而来：chaser_alarm、chaser_wakes、chaser_steps、chaser_hunts
  • 守卫不会凭空出现，被踩掉的不会回来
    由这些早期说法合并而来：chaser_hidden
  • 落到目标上，当且仅当这一步过关
    由这些早期说法合并而来：reach_goal
  • 输掉，当且仅当撞上下面任何一种情况
    由这些早期说法合并而来：game_over
  • 每按一下方向键，预算带就短一截，走没走动都一样
    由这些早期说法合并而来：hud_drain
  • 摆出新的一关，预算带回到满格不进 Lean 模型
    由这些早期说法合并而来：hud_reset

被推翻的说法

哨兵其实从来不走

foe_walks
  1. 原来以为

    画面里出现了红色的守卫，身上也有一个朝向记号。agent 照玩家的样子写下：它每步沿记号方向走一格，前面没桥才停下。

  2. 画面打脸

    第一遍游玩的第 25 到第 27 步，它面前明明是桥，却一连几步纹丝不动。

  3. 后来改成

    先退成一句只在出生点成立的否定式，最后改成正面的一句：哨兵永远不走，只盯着正前方那一格。曾经看上去的那次「动」，是它扑向走进它正前方的玩家，那一步是输局。

巡逻不是每按一下都走

patrol_steps
  1. 原来以为

    后来出现了橙色的巡逻，看上去每按一下方向键，它就沿朝向走一格。

  2. 画面打脸

    第一遍游玩的第 77 步，玩家朝一个没有桥的方向按键，没挪动；巡逻也原地没动，只有预算带短了一截。

  3. 后来改成

    改成：只有玩家真走了一步，巡逻才走一步；玩家被挡住，整个世界都停着。这就是首页的核心概念。

另外 2 个改写的故事

过关不等于新的一关

hud_reset
  1. 原来以为

    过关那一步，预算带回到满格。

  2. 画面打脸

    第二遍游玩的第 373 步通掉了最后一关，后面没有新关，预算带停在原处，没有回满。

  3. 后来改成

    改成：只有下一帧摆出了新的一关（画面上有目标），预算带才回满。

记号不跟着身子平移，而是转向

move_shiftmark_faces
  1. 原来以为

    玩家走一步，整块连同身上的记号一起平移。

  2. 画面打脸

    第 10 步向右走，新位置上的记号没有留在原来的相对位置，而是转到了朝右的那条边上。

  3. 后来改成

    位置和朝向分开说：身子平移一格，记号转向这一步的方向。

def _entities(g, body):
    """把「色 body 的格子 + 色15 记号」切成一个个 BLOCK×BLOCK 块。

    色8 和色12 可能同屏（第 3 关），色15 记号也就有多个；

    返回 [(top, left), ...]，按 (top, left) 排序。
    """
    body_cs = [(r, c) for r, row in enumerate(g)
               for c, v in enumerate(row) if v == body]
    marks = [(r, c) for r, row in enumerate(g)
             for c, v in enumerate(row) if v == FOE_MARK]
    out = []
    seen = set()
    for r0, c0 in body_cs:
        for top in range(r0 - BLOCK + 1, r0 + 1):
            for left in range(c0 - BLOCK + 1, c0 + 1):
                if (top, left) in seen:
                    continue
                cells = {(top + dr, left + dc)
                         for dr in range(BLOCK) for dc in range(BLOCK)}
                if not all(0 <= r < len(g) and 0 <= c < len(g[0])
                           for r, c in cells):

                       if g[r][c] == body or (r, c) in marks}
                if got == cells and any((r, c) in marks for r, c in cells):
                    seen.add((top, left))
                    out.append((top, left))
    return sorted(out)

def first_steps(adj, src, dst):
    """adj 上 src 走向 dst 的所有最短路第一步；不连通返回 None，同格返回空集。"""
    from collections import deque
    if src == dst:
        return set()
    dist = {dst: 0}
    q = deque([dst])
    while q:
        u = q.popleft()
        for v in adj.get(u, []):
            if v not in dist:
                dist[v] = dist[u] + 1
                q.append(v)
    if src not in dist:
        return None
    return {v for v in adj.get(src, []) if dist.get(v, 1 << 30) == dist[src] - 1}
