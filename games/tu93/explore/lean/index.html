这是个什么游戏回放对象规则形式化怎么给别人看

明写的缺口（6 条）——摆在最上面，不藏

  • 平行地踩进哨兵 / 巡逻（顺着它的朝向从背后踩）会怎样：语料里 0 次；模型选了「不算踩掉」
  • 追兵扑到玩家身上、与巡逻对穿（swap）：死法里这两支语料里 0 次，是照「巡逻落到玩家头上」补的
  • 追兵醒的距离按曼哈顿还是按桥图步数、刚醒那一步记号改不改、最短路并列挑哪条：三处语料上读数一样，模型是选的
  • 过关与被扑中同时发生时谁先：语料里 0 次；模型选了过关优先
  • RESET 不进模型：「重来一次把局面放回这一关的开局」是明处的假设（Unsolvable 的意思因此是「不经过重置就赢不了」）
  • 预算步数 B 是逐关量出来的常数（每关钉死成一个数），没找到它和版面的关系
