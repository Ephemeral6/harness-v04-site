Cell —— 落点格阵上的一个格（不是像素）。

## 判据 1：世界层不许出现像素

帧上一个落点占 3×3 像素，相邻落点之间隔一个 3×3 的中间块，所以相邻落点的
像素距离是 6。那是解析的事：parse 把像素坐标除掉 6、减掉相位，
上面每一层只见到「第几行第几列」。

## 判据 4：不带原点

Cell(0, 0) 是这一帧落点阵的相位原点（像素行列各对 6 取余之后的那一格），
不是帧的左上角。同一关里相位不变（玩家永远站在落点上），跨关就不可比——
一个 Cell 离开它那一关就没有意义，这是有意的。

# Cell —— 落点阵上的一格（对应 `objects/geometry/cell.py`）

不是像素：相邻落点在帧上隔 6 像素，那是解析的事。行、列都从 0 数起。

`move` 在第 0 行往上 / 第 0 列往左时**原地不动**（自然数减法）。这一支不会被用错：
每一次移动都先问 `linked`（两格之间有没有桥），而桥只连两个**不同**的相邻格，
`c.move d = c` 那一支上永远没有桥。
-/

import Obj.Geometry.Dir

namespace Game

structure Cell where
  row : Nat
  col : Nat
  deriving DecidableEq, Repr

namespace Cell

def move (c : Cell) : Dir → Cell
  | .up    => ⟨c.row - 1, c.col⟩
  | .down  => ⟨c.row + 1, c.col⟩
  | .left  => ⟨c.row, c.col - 1⟩
  | .right => ⟨c.row, c.col + 1⟩

/-- 曼哈顿距离，按格计。 -/
def dist (a b : Cell) : Nat :=
  (a.row - b.row) + (b.row - a.row) + (a.col - b.col) + (b.col - a.col)

end Cell
end Game

`Cell(0, 0)` 是这一帧落点阵的相位原点（像素行列各对 6 取余之后的那一格），
不是帧的左上角。同一关里相位不变（玩家永远站在落点上），跨关就不可比——

from __future__ import annotations

from dataclasses import dataclass

from .dir import Dir


@dataclass(frozen=True, order=True)
class Cell:
    """落点阵上的一格。行在前、列在后，从 0 数起。"""

    row: int
    col: int

    def __add__(self, d: Dir) -> "Cell":
        dr, dc = d.delta
        return Cell(self.row + dr, self.col + dc)

    def dist(self, other: "Cell") -> int:
        """曼哈顿距离，按格计。"""
        return abs(self.row - other.row) + abs(self.col - other.col)
