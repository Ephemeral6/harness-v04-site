## 这一帧长什么样（量出来的，不是猜的）

    第 63 行           预算带：左边一串色 6，右边一串色 0。剩几格 = 色 6 的个数
    第 0–62 行         版面：一张 3×3 像素块的格阵
                         · 块角相位每关不同（按帧自己量，不抄常数）；
                         · 行、列下标都是偶数的块 = 落点槽，有落点就不是底色；
                         · 一奇一偶的块 = 桥槽，整块色 2 就是一段桥；
                         · 两个都是奇数的块永远是底色。
    落点槽里能画的东西（一块 3×3）
        整块色 0                       空落点
        整块色 14                      目标
        8 格主体色 + 边中点 1 格记号     棋子：主体 9 + 记号 4 = 玩家；
                                          主体 8 / 12 / 13 + 记号 15 或 11 = 三种守卫

## 良构检查：同一个量的两种读法必须对得上

对不上就抛，让这一帧读不成世界——比某条规则判一次 FALSE 更早也更响。

    · 预算带：色 6 的个数 == 从左数连续色 6 的长度（也就是「6…6 0…0」这个形状）；
    · 格阵：底色以外的每一个像素都落在某个被认出来的块里；
    · 相位：所有落点槽的奇偶一致，桥槽恰好一奇一偶；
    · 桥两头都得是落点（「通向虚空的桥」读不成世界）；
    · 玩家恰好一个，目标至多一个。

「恰好几只守卫」「恰好一只追兵」不是良构检查——那是一次观察，
写进来会让别的关整批读不成世界（卡 01「不许把一次观察写成良构检查」）。

## 读不成的两类，这里只管抛、不管归类

归类由拿得到 meta 的那一层做（run_rules.py）：GAME_OVER 那一帧玩家已经被吃掉，
它不是一个局面，是 (a)；剩下读不成的才是 (b)，那一档必须是 0。

它的 Lean

没有：它是唯一碰像素的那一份，形式化那一层从它导出的观测起步（Obs/Replay.lean）。

"""帧 → 世界。**全局唯一碰像素的地方。**

上面每一层只认 `World` 的字段，读不到帧。

## 这一帧长什么样（量出来的，不是猜的）

    第 63 行           预算带：左边一串色 6，右边一串色 0。剩几格 = 色 6 的个数
    第 0–62 行         版面：一张 3×3 像素块的格阵
                         · 块角相位每关不同（按帧自己量，不抄常数）；
                         · 行、列下标都是偶数的块 = **落点槽**，有落点就不是底色；
                         · 一奇一偶的块 = **桥槽**，整块色 2 就是一段桥；
                         · 两个都是奇数的块永远是底色。
    落点槽里能画的东西（一块 3×3）
        整块色 0                       空落点
        整块色 14                      目标
        8 格主体色 + 边中点 1 格记号     棋子：主体 9 + 记号 4 = 玩家；
                                          主体 8 / 12 / 13 + 记号 15 或 11 = 三种守卫

## 良构检查：同一个量的两种读法必须对得上

对不上就抛，让这一帧读不成世界——比某条规则判一次 FALSE 更早也更响。

    · 预算带：色 6 的个数 == 从左数连续色 6 的长度（也就是「6…6 0…0」这个形状）；
    · 格阵：底色以外的每一个像素都落在某个被认出来的块里；
    · 相位：所有落点槽的奇偶一致，桥槽恰好一奇一偶；
    · 桥两头都得是落点（「通向虚空的桥」读不成世界）；
    · 玩家恰好一个，目标至多一个。

**「恰好几只守卫」「恰好一只追兵」不是良构检查**——那是一次观察，
写进来会让别的关整批读不成世界（卡 01「不许把一次观察写成良构检查」）。

## 读不成的两类，这里只管抛、不管归类

归类由拿得到 meta 的那一层做（`run_rules.py`）：GAME_OVER 那一帧玩家已经被吃掉，
它不是一个局面，是 (a)；剩下读不成的才是 (b)，那一档必须是 0。
"""
from __future__ import annotations

from .board.bridge import Bridge
from .geometry.cell import Cell
from .geometry.dir import Dir
from .pieces.guard import Guard
from .world import World

BG = 5
EMPTY = 0
BRIDGE = 2
TARGET = 14
HUD_ON, HUD_OFF = 6, 0
PLAYER_BODY, PLAYER_MARK = 9, 4
GUARD_BODY = {8: "sentries", 12: "patrols", 13: "chasers"}      # 主体色 → World 的哪个字段
MARK_CALM, MARK_ALERT = 15, 11
# 记号在块内的位置 → 朝向（四条边的中点）
MARK_AT = {(0, 1): Dir.UP, (2, 1): Dir.DOWN, (1, 0): Dir.LEFT, (1, 2): Dir.RIGHT}
H, W = 63, 64          # 版面区的行数（第 63 行是预算带）、列数
B = 3                  # 块边长
STRIDE = 2 * B         # 相邻落点的像素距离


class ParseError(Exception):
    """这一帧读不成一个世界。**这是一条可判错的话**，不是一次异常处理。"""


# 上游的动作名 → 方向。四个方向键各对一个方向（语料里每个都生效过几十次，见 analysis/Dir.txt）；
# RESET 不是方向，返回 None。**上游的字符串只在这里认一次。**
ACTIONS = {"ACTION1": Dir.UP, "ACTION2": Dir.DOWN, "ACTION3": Dir.LEFT, "ACTION4": Dir.RIGHT}


def parse_action(action: str) -> Dir | None:
    return ACTIONS.get(action)


def _block(g, r, c):
    return [g[r + i][c + j] for i in range(B) for j in range(B)]


def _piece(vals):
    """一块 3×3 若是棋子，返回 (主体色, 记号色, 朝向)；不是返回 None。"""
    cnt = {}
    for v in vals:
        cnt[v] = cnt.get(v, 0) + 1
    if len(cnt) != 2:
        return None
    body = max(cnt, key=cnt.get)
    if cnt[body] != B * B - 1:
        return None
    mark = min(cnt, key=cnt.get)
    k = vals.index(mark)
    d = MARK_AT.get((k // B, k % B))
    if d is None:
        return None
    return body, mark, d


def parse_hud(g) -> int:
    row = g[H]
    n = sum(1 for v in row if v == HUD_ON)
    if any(v not in (HUD_ON, HUD_OFF) for v in row) or any(v != HUD_ON for v in row[:n]):
        raise ParseError("预算带不是「6…6 0…0」的形状：两种读法（个数 / 前缀长）对不上")
    return n


def parse(frame) -> World:
    g = frame
    if len(g) != H + 1 or any(len(r) != W for r in g):
        raise ParseError(f"帧不是 {H + 1}×{W}")
    hud = parse_hud(g)

    fg = [(r, c) for r in range(H) for c in range(W) if g[r][c] != BG]
    if not fg:
        raise ParseError("版面区一个非底色像素都没有")
    r3, c3 = min(r for r, _ in fg) % B, min(c for _, c in fg) % B

    # 按 3 的相位切块；每个非底色像素都得落进一个完整的块
    blocks = {}
    for r in range(r3, H - B + 1, B):
        for c in range(c3, W - B + 1, B):
            v = _block(g, r, c)
            if any(x != BG for x in v):
                blocks[(r, c)] = v
    covered = {(r + i, c + j) for (r, c) in blocks for i in range(B) for j in range(B)}
    stray = [p for p in fg if p not in covered]
    if stray:
        raise ParseError(f"有 {len(stray)} 个非底色像素不落在任何块里（首个 {stray[0]}）")

    # 落点槽 vs 桥槽：桥槽整块是桥色，其余非底色块都是落点槽
    node_px, bridge_px = {}, []
    for (r, c), v in blocks.items():
        if all(x == BRIDGE for x in v):
            bridge_px.append((r, c))
        else:
            node_px[(r, c)] = v
    if not node_px:
        raise ParseError("一个落点都没有")
    pr = {r % STRIDE for r, _ in node_px}
    pc = {c % STRIDE for _, c in node_px}
    if len(pr) != 1 or len(pc) != 1:
        raise ParseError(f"落点槽的相位不一致：行 {sorted(pr)} 列 {sorted(pc)}")
    pr, pc = pr.pop(), pc.pop()

    def cell(r, c):
        return Cell((r - pr) // STRIDE, (c - pc) // STRIDE)

    nodes, player, target = set(), None, None
    guards = {k: [] for k in GUARD_BODY.values()}
    for (r, c), v in node_px.items():
        p = cell(r, c)
        nodes.add(p)
        if all(x == EMPTY for x in v):
            continue
        if all(x == TARGET for x in v):
            if target is not None:
                raise ParseError("目标不止一个")
            target = p
            continue
        pc_ = _piece(v)
        if pc_ is None:
            raise ParseError(f"落点槽 {(r, c)} 画的东西认不出：{sorted(set(v))}")
        body, mark, d = pc_
        if body == PLAYER_BODY and mark == PLAYER_MARK:
            if player is not None:
                raise ParseError("玩家不止一个")
            player = (p, d)
        elif body in GUARD_BODY and mark in (MARK_CALM, MARK_ALERT):
            guards[GUARD_BODY[body]].append(Guard(p, d, mark == MARK_ALERT))
        else:
            raise ParseError(f"落点槽 {(r, c)} 是棋子的形状，但主体/记号色 {body}/{mark} 不认识")
    if player is None:
        raise ParseError("没有玩家")

    bridges = set()
    for r, c in bridge_px:
        dr, dc = (r - pr) % STRIDE, (c - pc) % STRIDE
        if (dr, dc) == (B, 0):
            a, b = (r - B, c), (r + B, c)
        elif (dr, dc) == (0, B):
            a, b = (r, c - B), (r, c + B)
        else:
            raise ParseError(f"桥块 {(r, c)} 不在桥槽上（相位 {dr},{dc}）")
        if a not in node_px or b not in node_px:
            raise ParseError(f"桥块 {(r, c)} 有一头不是落点")
        bridges.add(Bridge.of(cell(*a), cell(*b)))

    # `World` 没有「落点」这个字段（卡 03 删了：它恒等于桥的端点集合）。
    # 于是一个不连任何桥的落点**表示不出来**——那就读不成，不许悄悄丢掉那一位。
    ends = {x for br in bridges for x in (br.a, br.b)}
    if nodes != ends:
        raise ParseError(f"有 {len(nodes - ends)} 个落点不连任何桥：World 表示不出孤立落点")

    return World(bridges=frozenset(bridges), target=target, player=player[0], facing=player[1],
                 sentries=tuple(sorted(guards["sentries"])), patrols=tuple(sorted(guards["patrols"])),
                 chasers=tuple(sorted(guards["chasers"])), hud=hud)
