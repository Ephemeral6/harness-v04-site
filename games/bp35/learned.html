它是怎么学出来的

agent 边玩边把看到的规律写成可检验的代码：每条都对接下来的每一步自动判对错。它在更早的一遍边摸索边打的通关里一共写过 26 条，其中 4 条当场就被后来的画面推翻、撤掉。统一整理时，其余的说法拿官方认证那一遍的录像逐条重判：计步条走满就输、被带到头顶住空处就死这类说法被这份录像驳倒；剩下的按「一步怎么走、点击怎么回应、什么算赢、怎么计数」合并成首页的规则。下文提到的步数，是摸索那一遍里的步数。

  • 按左或右，能进就挪一格，并转向那一边
    由这些早期说法合并而来：a3_left、a4_right、move_needs_floor
  • 每一步之后，玩家顺着重力被带到头

  • 点中开关，重力翻转

被推翻的说法

玩家不总是往上浮

ceiling_above_player
  1. 原来以为

    前几关里，玩家每一步之后都一路往上浮，直到头顶碰到东西。agent 写下：每个操作之后，玩家正上方那一格都不是液体——它像个气泡。

  2. 画面打脸

    第 4 关出现了红色的块。点开它，玩家整个往下掉，停下来时头顶就是液体。摸索那一遍的第 153 步，这条撤掉。

  3. 后来改成

    改成不挑方向：玩家总是贴着什么东西停住，不会悬在液体中间。再往后才弄清楚，红色块是开关，点它把重力翻过来；「往哪边带」成了模型里的一位状态。

「第 6 关打不通」

blocked_up_no_block8
  1. 原来以为

    摸索那一遍卡在第 6 关。agent 按当时写下的全部规则，把这一关整关画成状态图穷举，结论是没有赢法，并把它写成一条可判错的阻断说法：窗口里没有开关、玩家正在上浮、十字在玩家下方时，这一步不可能过关。

  2. 画面打脸

    官方认证的那一遍里，这一关用 41 步打通了。

  3. 后来改成

    这句话本身没错，错在把它读成了「这一关做不了」。它现在是模型里一条关于一步的推论：不点开关就够不着下方的十字；下一步点了开关，十字照样够得着。

另外 2 个改写的故事

计步条走满，游戏并没有结束

hud_full_kills
  1. 原来以为

    底部计步条每步多填一格。摸索时 agent 以为它是每关的步数上限：填满的那一步就输。

  2. 画面打脸

    认证那一遍的第 9 关，计步条填满一整行之后，换了一种颜色从头再填，游戏照常继续。

  3. 后来改成

    撤掉。计步条只记步数：每个操作加一格，填满一圈换色接着记。它是不是某种上限，这份录像说不了。

「棋盘除了玩家都不变」缩了三次

board_static
  1. 原来以为

    一开始写的是：一步之内，除了底部计步条和玩家所在的格，整个棋盘逐格不变。

  2. 画面打脸

    先是点开绿色块改了棋盘；缩到只管左右走，又碰上玩家右移一格、底下一大片跟着变；再缩到只管玩家那一行以上，又被一次上浮时的整屏滚动打破。

  3. 后来改成

    拆成两件事：画面整体滚动是镜头跟着玩家走，地形本身不变。统一整理时把两帧对齐、量出镜头挪了几行，「地形不变」才成了一条每步都能核的规则。

def phase_of(g) -> tuple[int, int]:
    """这一帧的格点相位 (行相位, 列相位)。**格点会动**——第 3 关点色8 翻转重力之后，
    整块棋盘相对帧往下挪了 2 行，行相位从 1 变成 3；写死 PHASE 会让此后所有读数系统性偏两行。

    判法：色 3 的点阵在每个墙格里固定长在局部 (0,1)、(3,0)、(4,3) 上，
    所以行相位 p 满足「点的行号 mod 6 ∈ {p, p+3, p+4}」、列相位 q 满足「列号 mod 6 ∈ {q, q+1, q+3}」。
    取让命中数最大的那个 p / q（块的四角也是色 3，会给别的相位加一点噪声，用 argmax 而不是集合相等）。
    """
    key = id(g)
    hit = _PH_CACHE.get(key)
    if hit is not None and hit[0] is g:
        return hit[1]
    rows = [0] * 6
    cols = [0] * 6
    for r in range(HUD_ROW):
        row = g[r]
        rr = r % 6
        for c, v in enumerate(row):
            if v == DOT:
                rows[rr] += 1
                cols[c % 6] += 1
    if not any(rows):
        return PHASE
    pr = max(range(6), key=lambda p: rows[p] + rows[(p + 3) % 6] + rows[(p + 4) % 6])
    pc = max(range(6), key=lambda q: cols[q] + cols[(q + 1) % 6] + cols[(q + 3) % 6])
    if len(_PH_CACHE) > 512:
        _PH_CACHE.clear()
    _PH_CACHE[key] = (g, (pr, pc))
    return (pr, pc)
