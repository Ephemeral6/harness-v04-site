/-- 这一步现实里的下一帧（只有 `.next` 才有；别的给一个一眼露馅的空帧）。 -/
def Step.nextSeen (s : Step) : Seen :=
  match s.expect with
  | .next o => o
  | _       => dummySeen

/-- 从 **seq** `want` 那一条起连着取 `len` 条的（动作, 下一帧）。取不到给空表——所以每段配 `_len`。 -/
def playFrom (want len : Nat) : List (Act × Seen) :=
  ((steps.dropWhile (fun s => s.seq != want)).take len).map (fun s => (s.act, s.nextSeen))

/-- 从 **seq** `want` 起连着取 `len` 个动作。 -/
def actsFrom (want len : Nat) : List Act :=
  ((steps.dropWhile (fun s => s.seq != want)).take len).map (fun s => s.act)

/-- seq `want` 那一步动作之前的那一帧。 -/
def prevAt (want : Nat) : Seen :=
  ((steps.find? (fun s => s.seq == want)).map (fun s => s.prev)).getD dummySeen
