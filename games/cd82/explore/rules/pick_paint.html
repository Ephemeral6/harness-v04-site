它说什么

点中一个色环（整块 5×5 都算），当前颜料色变成那个环的芯色；其余一切动作颜料色不变。

论域

同一关之内的每一步都管。重来、换关、新开一局归 back_to_start。

明确不主张

不主张杯里的液体、小杯的腔、下划线怎么变——它们是颜料色的画法（parse 的良构检查），不是另外几件事。不主张点中与当前同色的环有什么额外效果。

def pickPaint (b : Board) (p : Color) (r c : Nat) : Color :=
