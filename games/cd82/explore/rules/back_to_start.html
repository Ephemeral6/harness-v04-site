RESET、换关（非最后一关）、新开一局之后，工位 = 6（开口朝南）、颜料色 = 15、容器 100 格全是 0、预算条满 64 格。是「设成」，不是「保留」。

论域

只管 RESET 与换关、新开一局那几步。同一关之内的普通一步归 move/。最后一关通关那一步不换盘，不归这里。

明确不主张

不主张新一关的目标图与色板（换关之前那一帧里根本没有）。两处分不开的地方：「颜料色设成 15」与「设成第二个色环的芯色」在全语料的每张色板上给出同一个值；「容器清成 0」与「清成这一关开局时的颜色」也分不开（每关开局都是 0）。要分开得等一张第二个环不是 15、或开局容器不是 0 的盘——语料里没有。

# Rule/Respond/BackToStart —— 重来放回开局（对应 `rule/respond/back_to_start.py`，身份：**定义**）

重来之后是一个**固定**的局面：工位 6、颜料色 15、容器全 0、钟归零。
（Python 那条规则还管「换关之后也是这个局面」；Lean 里换关那一步的结果是 `won`，**不带下一个状态**——
下一关的版面模型说不出来。所以换关那一半在这里只作为同一个开局的定义被复用，`step` 不用它。）

**两处分不开的地方**：「颜料色 15」与「第二个色环的芯色」、「容器清成 0」与「清成这一关开局的颜色」，
在全语料的每张盘上给出同一个值。这里取前者。
-/
