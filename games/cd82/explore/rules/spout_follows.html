它说什么

小杯在场 ⇔ 大杯此刻在正向工位上 且 这一关有小杯。「这一关有没有小杯」一关之内不变：上一帧在正向工位上时，它就是上一帧小杯在不在场。

论域

同一关之内的每一步都管，含重来（重来之后工位是 6，正向）。上一帧在斜向工位、下一帧在正向工位时不管：那时「这一关有没有小杯」上一帧读不出来（斜向工位上谁都不在场）——这一类单独计数。换关、新开一局、终局之后不管。

明确不主张

不主张哪几关有小杯（语料里是第 3~6 关有、第 1~2 关没有；起点册子那条「色环 ≥ 7 个」的阈值是外推，不收）。不主张小杯的格子——那是工位的函数（objects/stage/spout.py）。

def scope_(w, action, _nw, ctx):
    mark = (ctx or {}).get("mark", "")
    if mark == "换关":
        return WHY_LEVEL
    if mark == "新开一局":
        return WHY_NEWGAME
    if mark == "终局之后" and ctx.get("level_prev") != ctx.get("level_next"):
        return WHY_OVER
    # 下一帧会不会落在正向工位，按动作前就定得下来的那一份判（论域不许偷看下一帧）
    goes_to = START if action.startswith("RESET") else turned(w.pose, action)
    if not cardinal(w.pose) and cardinal(goes_to):
        return WHY_UNREADABLE
    return None


def assert_(w, action, nw, ctx):
    return nw.spout == (cardinal(nw.pose) and w.spout)
