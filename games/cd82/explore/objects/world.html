World —— 这一局的全部状态。字段就是这一局的对象。

    target    面板里的目标图          一关之内不变（版面）
    palette   横带里的一排色环         一关之内不变（版面）
    vessel    容器里 10×10 的颜色      会变：倾倒、盖章
    pose      大杯的工位 0..7          会变：四个方向键
    paint     当前颜料色               会变：点色环
    spout     小杯此刻在不在场         会变：跟着工位
    budget    预算条的长度 0..64       会变：每一步

每个字段「抹掉它，哪一对世界从能区分变成不能区分」写在 analysis/<对象>.txt，
读数（分离表、消融）在 analysis/field_split.txt 与 analysis/字段-*.txt。

不在这里的东西，以及为什么（每一样都是一次删除，死因写在 analysis/record.txt）：

    容器的位置      全语料恒定 → 常数 stage.vessel.BOX
    杯的格子        工位号的函数 → stage.cup.drawing
    小杯的格子      工位号的函数 → stage.spout.drawing
    下划线的位置    颜料色的另一种读法 → parse 的良构检查
    关卡号 / 终局   上游给的 → 规则从 ctx 读
    走了几步        帧上读不出 → 规则按纤维判

# Obj/World —— 这一局的全部状态（对应 `objects/world.py`）

Python 的 `World` 七个字段在这里分成两半：

    Board（版面，一关之内不变）   target · palette · hasSpout
    St   （状态，会变）           vessel · pose · paint · clock

**`Board` 不是 `St` 的字段，它是 `step` 的参数。** 于是「走一步版面不会变」不用证——
`step` 的结果类型里没有能放一张新版面的位置，这句话**写不出来**（规则 `board_static` 的身份：不进模型）。

两处和 Python 那一份不一样，都写在明处：

* `spout`（小杯在不在场）Python 里是帧上读到的一位；这里不存，它是 `hasSpout && cardinal pose`。
  `hasSpout` 在斜向工位的帧上读不出来，所以它住在版面里，按**整关取并集**的口径给（见 `Obs/Replay`）。
* `clock`（自最近一次归零走了几步）Python 里没有——**帧上读不出来**。观测只看得见 `barOf clock`，
  逐条判的时候按纤维取（这个长度可能对应的每个 `clock`）。
-/

import Obj.Panel.Target
import Obj.Palette.Swatch
import Obj.Palette.Paint
import Obj.Stage.Vessel
import Obj.Stage.Cup
import Obj.Stage.Spout
import Obj.Hud.Budget

namespace Game

/-- 版面：一关之内不变。 -/
structure Board where
  target   : Target
  palette  : List Swatch
  hasSpout : Bool

/-- 状态。 -/
structure St where
  vessel : Vessel
  pose   : Pose
  paint  : Color
  clock  : Nat

/-- 动作：四个方向键、倾倒、带坐标的点击（行, 列）、重来。 -/
inductive Act where
  | up | down | left | right
  | pour
  | click (r c : Nat)
  | reset
  deriving DecidableEq, Repr

/-- 一步的结果。**结果类型里没有编出来的分支**：
    过关那一步的下一帧是下一关的盘、终局那一步之后局面结束——模型都不描述，所以 `won` / `over` 不带状态。 -/
inductive Res where
  | ok (s : St)
  | won
  | over

/-- 帧上看得见的那一部分（和 parse 读出来的逐项对应，版面除外）。 -/
structure Seen where
  vessel : List Nat
  pose   : Nat
  paint  : Nat
  spout  : Bool
  bar    : Nat
  deriving DecidableEq, Repr

end Game
