它是什么（源码文档）

小杯 —— 从第 3 关（关号 2）起，大杯正对容器时，它外侧那只口朝容器的小杯。

世界里它只记一位：此刻在不在场（World.spout）。在场时它的格子由 drawing(pose) 画出：

    描边 14 格（色 2）   —— 这是控件：点中它 = 盖章（规则层 stamp）
    颈   2 格（色 0）    —— 恒为 0
    腔   12 格           —— 3 深 × 4 宽，颜色 = 当前颜料色（World.paint）

## 画法（判据 3：对称）

工位 6（大杯开口朝南）那一张是一组实测格（第一次在场的帧上量的，见 analysis/Spout.txt）；
另外三个正向工位由它绕容器中心整格转 90 度得到——和大杯同一个变换。
斜向工位上它不在场，所以没有斜向的画法；parse 要是在斜向帧上看到它，那一帧读不成世界。

## 为什么「在不在场」是一位独立的信息

它不是工位号的函数：第 1、2 关的正向工位上它也不在场。
而「这一关有没有小杯」在斜向帧上读不出来（那时谁都不在场），
所以它是一位帧上的事实，不是版面上的常数。「它什么时候回来」归规则层说。

为什么删不掉它

对象：小杯（World.spout，在场与否）　文件 objects/stage/spout.py ↔ lean2/Obj/Stage/Spout.lean

1. 它记的是什么
   小杯此刻在不在场。在场时它的 14 格描边、2 格颈（色 0）、12 格腔（颜料色）由工位画出：
   工位 6 那一张是第一次在场的帧上量的实测格（第 3 关开局，行 18..22 × 列 29..34），另三个正向工位绕容器中心转 90 度。

2. 哪几条规则读它
   spout_follows、stamp、pick_paint、vessel_still、level_up（后四条经 derive/click.py：没在场就点不中描边）。

3. 抹成常量，判决变几处
   全册 78。逐条：spout_follows 25、stamp 19、vessel_still 19、level_up 15。

4. 分离表
   分不开（卡 03 前后都是）。全语料里 (target, pose) ⇒ spout：在场与否由「这一关」和「工位」决定，
   找不出「这两样相同而在场不同」的一对。卡 03 之前 spout_cells 与 spout 同生共死（(pose, spout) ⇒ spout_cells）→ 合并。

为什么不删：消融 78 处；而且它不是现有字段的函数——「这一关有没有小杯」在斜向工位的帧上读不出来，
   这一位只在正向工位的帧上露出来。它是那一位（hasSpout，关的属性）在帧上的投影。
   Lean 里拆成两半：hasSpout 住在 Board（整关取并集的口径），在场 = hasSpout ∧ 正向（规则 SpoutFollows）。

欠账：哪几关有小杯（第 3~6 关有、第 1~2 关没有）和色环个数（7 vs 2/3）、关号在语料里分不开。
   起点册子的「色环 ≥ 7 个」阈值不收。能分开的实验：一关色环少于 7 个而有小杯，或反过来。

/-
# Obj/Stage/Spout —— 小杯（对应 `objects/stage/spout.py`）

在场与否不存在状态里：它由「这一关有没有小杯」（`Board.hasSpout`）和工位决定（规则 `SpoutFollows`）。
这里只放它的**描边在哪**——点中描边是盖章的触发面。

工位 6（大杯开口朝南）上描边是 14 格实测格；其余正向工位由它绕容器中心 (38.5, 31.5)
逆时针转 90 度得到：(r, c) ↦ (70 − c, r − 7)。
判点击时反过来走：把点击坐标**顺时针**转回工位 6 的坐标系，(r, c) ↦ (c + 7, 70 − r)，再查那 14 格。
-/

import Obj.Stage.Cup

namespace Game

/-- 工位 6 上小杯的描边（绝对坐标，行在前）。 -/
def rim6 : List (Nat × Nat) :=
  [(18, 30), (18, 31), (18, 32), (18, 33),
   (19, 29), (19, 30), (19, 33), (19, 34),
   (20, 29), (21, 29), (22, 29), (20, 34), (21, 34), (22, 34)]

/-- 绕容器中心顺时针转 90 度（逆时针那一步的逆）。点击坐标都在 0..63 里，70 − r 不会截断。 -/
def unrot (p : Nat × Nat) : Nat × Nat := (p.2 + 7, 70 - p.1)

/-- 工位 p 要逆时针转几次才从工位 6 到达（只对正向工位有意义）。 -/
def turnsFrom6 (p : Pose) : Nat := ((p + 2) / 2) % 4

/-- 点在 (r, c) 是不是点中了工位 p 上小杯的描边（p 须是正向工位）。 -/
def rimHit (p : Pose) (r c : Nat) : Bool :=
  cardinal p && rim6.contains (Nat.repeat unrot (turnsFrom6 p) (r, c))

end Game
