Swatch —— 横带里的一个色环：5×5 的色 4 框，芯 3×3 是一种颜料色。整块 5×5 是按钮。

## 为什么按结构认

色环的个数和颜色每关不同（2 个 / 3 个 / 7 个），位置也跟着变。
所以 parse 按「5×5、16 格的色 4 空心方」找它，不按列号写死。

为什么删不掉它

对象：色板（World.palette，一排 Swatch）　文件 objects/palette/swatch.py ↔ lean2/Obj/Palette/Swatch.lean

1. 它记的是什么
   横带里每个色环的 5×5 位置和芯色，按列从左到右。第 1 关 2 个、第 2 关 3 个、第 3~6 关 7 个。

2. 哪几条规则读它
   pick_paint（点中哪个环）、board_static；stamp / vessel_still / level_up 经 derive/click.py 读（先判是不是点中了环）。

3. 抹成常量，判决变几处
   全册 90，全部来自 pick_paint。其余几条经 click 读它，但语料里点小杯描边的那几下从不落在横带上，
   所以换一张色板对它们没影响——读者点得出、消融却不变，是这一位在那几条上从没用上（卡 02 第一种不一致）。

4. 分离表
   分不开（卡 03 前后都是）。原因：全语料里色板由目标图决定（target ⇒ palette：同一张目标图只配过一张色板），
   找不出「目标图相同而色板不同」的一对。这是「语料分不开」，不是「没人读」（消融 90 处）也不是同生共死
   （palette 不决定 target：第 3~6 关同一张色板配了四张目标图）。

处置：留着，写成欠账。能把它分开的实验：同一张目标图配一张不同的色板（例如拿掉一个环）。
   Lean 里钥匙一正是这个实验的纸面版：第 2 关拿掉芯色 14 的环 ⇒ 不经过重来就赢不了（Proof/Keys.color_unsolvable），
   对照盘（真实色板）赢得了——色板这一位在模型里承重。

# Obj/Palette/Swatch —— 一个色环（对应 `objects/palette/swatch.py`）

5×5 的按钮，芯是一种颜料色。点中它（整块 5×5 都算）换颜料。
-/

import Obj.Geometry.Box

namespace Game

structure Swatch where
  box   : Box
  color : Nat
  deriving DecidableEq, Repr

/-- 点在 (r, c) 点中了哪个色环；没点中返回 `none`。按列从左到右找第一个。 -/
def swatchHit : List Swatch → Nat → Nat → Option Swatch
  | [],      _, _ => none
  | s :: ss, r, c => if s.box.contains r c then some s else swatchHit ss r c

end Game
