Vessel —— 容器：舞台正中那块 10×10 的画布。这一局唯一被评判、也唯一能被涂色的东西。

## 字段只有内容，没有位置

它在全语料每一帧里都在同一个地方（行 34..43 × 列 27..36）。卡 03 的判据：
恒定的一位不带信息，删。所以位置不是世界的字段，是这里的一个常数 BOX；
舞台上别的东西（杯的八个工位、小杯、倾倒的分界线）都相对它的中心 HUB 摆。

这一刀的代价写在明处：「容器换了位置，杯跟着它走」这句话现在表示不出来。
能把它和「杯的工位是绝对坐标」分开的实验只有一种：一关里容器换了位置。
语料里没有这样的关（欠账，见 analysis/Vessel.txt）。
而 parse 会让这件事响：容器不在 BOX 上，那一帧的良构检查过不去，读不成世界。

## 判据 1：内容按格存，不按像素存

一格一个颜色号。0..15 里哪些算「颜料」不在这里定——那是色板说的。

# Obj/Stage/Vessel —— 容器：10×10 的画布（对应 `objects/stage/vessel.py`）

世界里只存内容（每格一个颜色号），不存位置——位置全语料恒定，是常数。
内容写成**函数** `Nat → Nat → Nat`（行 → 列 → 颜色）：倒、盖都是「这几格改成颜料色，别的照旧」，
写成函数时这句话就是一个 `if`，证明里按格拆开最省事；和观测比的时候再按格摊成一张表（`tab`）。
-/

namespace Game

def SIZE : Nat := 10

/-- 容器内容。只看 `r < 10 ∧ c < 10` 的那 100 格。 -/
abbrev Vessel := Nat → Nat → Nat

/-- 摊成一张表：行在前，共 100 格。**和观测比只比这张表**。 -/
def Vessel.tab (v : Vessel) : List Nat :=
  (List.range (SIZE * SIZE)).map (fun i => v (i / SIZE) (i % SIZE))

/-- 一张表 → 容器（越界的格给 0；只有 100 格那一段有意义）。 -/
def Vessel.ofTab (l : List Nat) : Vessel :=
  fun r c => (l[r * SIZE + c]?).getD 0

/-- 两个容器逐格相等（100 格）。 -/
def Vessel.same (a b : Vessel) : Bool :=
  (List.range SIZE).all fun r => (List.range SIZE).all fun c => a r c == b r c

end Game
