它说什么

关卡号往前走一格，当且仅当这一步之后每一块（带壳的、裸的）占的格都正好等于某个框的内部，而且块和框一样多。

它明确不主张什么

  • 下一关长什么样：模型不描述（换关那一帧整屏重画）
  • 框线缺了一段（门带长在框线的位置上、或门带被推走了）算不算框：这条按内部的格比，不看框线
  • 块的核心是什么颜色（被没被选中过）：不影响过关

def scope_(prev, action, nxt, ctx=None):
    if not (is_dir(action) or is_click(action)):
        return "RESET → reset_restores"
    if not ctx or ctx.get("level_prev") is None:
        return "ctx 缺 level"
    return None


def assert_(prev, action, nxt, ctx=None):
    w = world(prev)
    won = all_seated(after(w, norm(action)))
    return verdict(won == (ctx["level_next"] != ctx["level_prev"]))
