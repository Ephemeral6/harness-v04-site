组：derive
这是个什么游戏回放对象规则形式化怎么给别人看

它是什么

一步之后：把几条规则各自的那一句拼起来，算出下一帧的世界。

由什么组成：space（前面那一排）+ slide（推 / 扫的走法）+ strike（谁在门带前面）
+ gate_clock（门带数拍子）+ World.selected / World.retired。

## 三个常数，各是哪条规则的主张

    KICK   = 5   被推的东西最多走几格          ← rule/一步怎么走/push_shoves.py
    STRIKE = 3   被门带扫的东西最多走几格      ← rule/世界怎么回应/gate_strikes.py
    REACH  = 3   门带扫得到前方几格以内的东西   ← 同上

它们写在这里只因为 after 要用；改它们等于改那两条规则，所以变异测试从这里下手。

## 拼法（一个方向动作）

    1. 被操纵的那一块朝 d 紧贴的那一排里有东西（块或门带）⇒ 推：
         它自己不动；贴着的那几样各按 slide(KICK) 走；落点压到谁，谁朝 d 让开
       否则那一排里有墙或带 ⇒ 不动；否则挪一格
    2. 每条门带数一拍；数满一圈（归零）的那几条，按动作生效之后的位置
       扫它正前方 REACH 格以内的块：各按 slide(STRIKE) 朝带子长的方向走，落点压到谁谁让开

点击（ACTION6:x,y）：点中一块带壳的、而且不是正被操纵的那一块 ⇒ 换成它，原来那块记进 retired；
别的一概不变，门带不数拍。

## 这里算不出来的一位

数到 0 的门带朝哪头长，帧上读不出。这一拍数到 1 时它从哪头长出来，这里给不出——
after 在那种门带上把朝向留成 None，由调用方决定怎么比（规则只比拍数；模型那一层带着隐藏的朝向）。

它的 Lean

不进 Lean：把几条规则拼成下一帧 —— Lean 那边这是 `Step.lean` 的分发，不是一份对象

"""**一步之后**：把几条规则各自的那一句拼起来，算出下一帧的世界。

由什么组成：`space`（前面那一排）+ `slide`（推 / 扫的走法）+ `strike`（谁在门带前面）
+ `gate_clock`（门带数拍子）+ `World.selected` / `World.retired`。

## 三个常数，各是哪条规则的主张

    KICK   = 5   被推的东西最多走几格          ← rule/一步怎么走/push_shoves.py
    STRIKE = 3   被门带扫的东西最多走几格      ← rule/世界怎么回应/gate_strikes.py
    REACH  = 3   门带扫得到前方几格以内的东西   ← 同上

它们写在这里只因为 `after` 要用；**改它们等于改那两条规则**，所以变异测试从这里下手。

## 拼法（一个方向动作）

    1. 被操纵的那一块朝 d 紧贴的那一排里有东西（块或门带）⇒ **推**：
         它自己不动；贴着的那几样各按 slide(KICK) 走；落点压到谁，谁朝 d 让开
       否则那一排里有墙或带 ⇒ 不动；否则挪一格
    2. 每条门带数一拍；数满一圈（归零）的那几条，**按动作生效之后的位置**
       扫它正前方 REACH 格以内的块：各按 slide(STRIKE) 朝带子长的方向走，落点压到谁谁让开

点击（ACTION6:x,y）：点中一块带壳的、而且不是正被操纵的那一块 ⇒ 换成它，原来那块记进 retired；
别的一概不变，**门带不数拍**。

## 这里算不出来的一位

数到 0 的门带朝哪头长，帧上读不出。这一拍数到 1 时它从哪头长出来，这里给不出——
`after` 在那种门带上把朝向留成 None，由调用方决定怎么比（规则只比拍数；模型那一层带着隐藏的朝向）。
"""
from __future__ import annotations

from dataclasses import replace

from objects import Cell, Gate, Piece

from .gate_clock import growth, layers, ticked, wraps
from .slide import cascade, slide
from .space import dir_of, front, shift
from .strike import in_front
from .things import me_key, table

KICK = 5
STRIKE = 3
REACH = 3


def click_cell(w, action: str) -> Cell | None:
    """ACTION6:x,y 点的是哪一格（x 是列、y 是行，像素）。不是点击返回 None。"""
    if not action.startswith("ACTION6:"):
        return None
    x, y = (int(v) for v in action.split(":")[1].split(","))
    pr, pc = w.phase
    return Cell((y - pr) // 3, (x - pc) // 3)


def clicked_piece(w, action: str):
    c = click_cell(w, action)
    if c is None:
        return None
    for p in w.pieces:
        if c in p.cells:
            return p
    return None


def moves(w, d):
    """方向动作 d 之后每样东西在哪。返回 (pos, pushed, struck)：
    pos = {key: 格集合}；pushed = 被推的那几样的 key；struck = [(门带 key, 方向, [被扫的 key])]。"""
    tab = table(w)
    me = me_key(w)
    pos = dict(tab)
    pushed = []
    if me is not None:
        strip = front(tab[me], d)
        pushed = [k for k in tab if k != me and tab[k] & strip]
        if pushed:
            for k in pushed:
                pos[k] = slide(w, tab[k], d, KICK)
            cascade(w, pos, list(pushed), d, frozen={me})
        elif not (strip & (w.walls | w.bands)):
            pos[me] = shift(tab[me], d)
    struck = []
    for i, g in enumerate(w.gates):
        if not wraps(g):
            continue
        D = growth(g)
        gk = ("g", i)
        hit = [k for k in pos if k[0] == "p" and in_front(w, pos[gk], D, pos[k], REACH)]
        for k in hit:
            pos[k] = slide(w, pos[k], D, STRIKE)
        if hit:
            cascade(w, pos, list(hit), D, frozen={gk})
        struck.append((gk, D, hit))
    return pos, pushed, struck


def after(w, action: str):
    """一步之后的世界（RESET 不在这里：模型不描述它）。门带朝向算不出的那几条留 None。"""
    d = dir_of(action)
    if d is not None:
        pos, _, _ = moves(w, d)
        new_pieces = []
        sel, ret = None, set()
        for i, p in enumerate(w.pieces):
            q = Piece(pos[("p", i)], p.shelled)
            new_pieces.append(q)
            if p.anchor == w.selected:
                sel = q.anchor
            if p.anchor in w.retired:
                ret.add(q.anchor)
        new_gates = []
        for i, g in enumerate(w.gates):
            n = ticked(g)
            if n is None:
                new_gates.append(Gate(pos[("g", i)], None, None, -1))      # 拍数也算不出
            elif n == 0:
                new_gates.append(Gate(pos[("g", i)], None, None, 0))
            elif g.count == 0:
                new_gates.append(Gate(pos[("g", i)], None, None, n))       # 朝向藏着
            else:
                new_gates.append(Gate(pos[("g", i)], g.axis, g.sign, n))
        return replace(w, pieces=tuple(sorted(new_pieces)), selected=sel,
                       retired=frozenset(ret), gates=tuple(sorted(new_gates)))
    p = clicked_piece(w, action)
    if p is not None and p.shelled and p.anchor != w.selected:
        ret = set(w.retired) - {p.anchor}
        if w.selected is not None:
            ret.add(w.selected)
        return replace(w, selected=p.anchor, retired=frozenset(ret))
    return w
