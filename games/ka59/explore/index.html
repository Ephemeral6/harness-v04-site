明写的缺口（摆在最上面）

  • 这一关的预算总步数 B 帧上读不出来，是拟合的常数（第 1、3 关 127 / 128 这批语料分不开，取 128）。
  • 数到 0 的门带朝哪头长帧上读不出来；每关开局用的是「整关口径」（同一关后面的帧上读到的），比玩家在开局那一帧多知道一位。
  • 「重来一次把局面放回开局」不进模型，是一条明写的假设：语料里 102 次 RESET 全都对上（reset_restores），没被驳倒不构成证明。被认证那一段每关一口气走完，每关的见证路线用不上它。
  • Unsolvable 的准确意思是「不经过 RESET 赢不了」——RESET 不是模型里的动作。

盘上有几块东西和几个空框。把每一块推进一个形状正好合身的框里，这一关就过了。

你一次只操纵一块（亮着的那块）。方向键让它挪一格；前面贴着别的东西时，它自己不动， 把那样东西朝同一方向推出去最多 5 格——撞墙才停，停在青色的「带」上停不住，会一路滑出去。 点一下别的带壳块，就换成操纵它。

后几关有门带：一条会数拍子的长条，每按一次方向键长一层，数满一圈就归零， 归零那一拍把它正前方的块扫出去 3 格。门带自己也能被推走。屏幕最下面一行是预算条， 每一步都往下走一点，走空了这一关就输了。

你能做的只有两件事

  • 方向键（ACTION1 上 / 2 下 / 3 左 / 4 右）：被操纵的那一块挪一格，或者推它前面贴着的东西。
  • 点一下（ACTION6:x,y）：点中另一块带壳的，就换成操纵它（原来那块核心变暗）；点在别处什么都不变。 点击不数门带的拍子，但照样花掉预算。

挡路的有三样，后果完全不同

墙谁都挡：被操纵的块走不进去，被推 / 被扫的东西撞上就停。
带（青色）挡被操纵的那一块；可是被推的东西不停在上面——落在带上就接着滑，直到离开带。
框线不挡。块能压上去、能走进去——框只是「嵌进来就算数」的那片地方。

推：被操纵的块贴着另一块按方向键，自己不动，那一块被推出去。

门带归零的那一拍：动作照常生效，然后正前方的块被扫出去。
