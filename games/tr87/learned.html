它是怎么学出来的

agent 边玩边把看到的规律写成可检验的代码：每条都对接下来的每一步自动判对错。它一共写过 13 条，其中 3 条被后来的画面推翻并撤掉；其余的在通关之后按「按一下会怎样」「什么算赢」重新合并，成了首页的规则。

每条规则的来历

  • 左右键：焦点走到下一串或上一串，走到头绕回
    由这些早期说法合并而来：cursor_lr、focus_move
  • 上下键：焦点那一串里每个字形的形状转一格
    由这些早期说法合并而来：shape_step
  • 按完一下，答题条逐格与目标同形，当且仅当这一关结束
    由这些早期说法合并而来：win_rule、win_prev
  • 按一下，别处一位都不动
    由这些早期说法合并而来：only_focus、glyph_local、cursor_lr
  • 每按一下，计数条要么不变、要么多吃一格不进 Lean 模型
    由这些早期说法合并而来：budget_bar
  • 过关之后的新一关：焦点停在第一站，计数条清空不进 Lean 模型
    由这些早期说法合并而来：—
  • 上下键不改每一格的朝向不进 Lean 模型
    由这些早期说法合并而来：wheels

被推翻的说法

每个位置一张环表，3 张表一起作废

wheel_l0wheel_l1wheel_l2
  1. 原来以为

    前几关里，agent 给答题条上每个位置手工记下一张环：按一下上键，这一格的字形沿它自己那张环往前走一格。每关一张表。

  2. 画面打脸

    三关的环表没有一张对得上：同一个字形，放在不同的位置、不同的关里，下一步变成的样子不一样。

  3. 后来改成

    改成把形状和朝向拆开：字形按形状族归类，每族的形状循环成一个环，上下键只改形状在环上的位置；每一格另外固定着一个朝向变换，画出来的是这个变换作用在标准形状上的样子。

计数条「每两步吃一格」

budget_bar
  1. 原来以为

    第一关量出来：每走满两步，计数条从右端多吃一格。

  2. 画面打脸

    拿到全部关卡的录像上检验，最后一关变成了隔更多步才吃一格；而且「这一步吃不吃」取决于这一关已经走了几步，画面上读不出来。

  3. 后来改成

    改口成画面上判得了的说法：同一关之内每按一下，计数条要么不变、要么正好多吃一格，从不倒退。这一条只在录像上检验，不进模型。

另外 2 个改写的故事

写死了第一关的坐标

cursor_lrglyph_local
  1. 原来以为

    答题条上有几个字形位、各在哪一列，被写成了固定的数；还断言一次按键的帧差只落在光标框住的格子里。

  2. 画面打脸

    换关以后版面变了，写死的坐标全部失效；计数条每隔几步从右端吃一格，这一格也不在光标框里。

  3. 后来改成

    改成每一帧从画面上认出答题行和格数，并把计数条那一行排除在「只动光标那一格」之外。

朝向机制改了 7 版

wheels
  1. 原来以为

    每一格的朝向变换，靠「已知的环都同意它下一步长什么样」来推。

  2. 画面打脸

    一个字形同时落在一条已知的环和一条还没量全的弧上：已知的环都同意，下一步却不是那个样子。

  3. 后来改成

    改成只在候选变换一致时下结论：字形不对称时变换唯一；字形有对称性时，只要求画出来的落在候选集合里。

def _wins(prev, out):
    """这一按之后答题条是不是就处处与目标同余了。是的话这一关当场结束（win_rule），
    而结束之后整块版面重画，这条概念对它没有发言权。"""
    g = [list(row) for row in prev]
    for (r, c), v in _cells(prev, out).items():

def _step(prev, action, ctx):
    """返回 [(行, 列, 目标位图)…]（只含说得出口的那些格）；条件不满足返回 None。"""
    if ctx is not None and ctx.get("level_prev") != ctx.get("level_next"):
        return None
    if action not in ("ACTION1", "ACTION2"):
        return None
    run = focus_run(prev)
    if not run:
        return None
    table = NEXT if action == "ACTION1" else PREV
    out = []
    for r0, c0 in run:
        v = glyph(prev, r0, c0)
        if len(HOME.get(v, ())) != 1:     # 没量到过，或者落在两条以上结构上
            continue
        cands = table.get(v)
        if not cands or len(cands) != 1:  # 弧的端点：这个方向上没有已量到的邻居
            continue
        out.append((r0, c0, next(iter(cands))))
    if not out or _wins(prev, out):
        return None
    return out


def assert_(prev, action, nxt, ctx=None):
    got = _step(prev, action, ctx)
    if got is None:
        return "NA"
    for r0, c0, want in got:
        if glyph(nxt, r0, c0) != want:
            return "FALSE"
    return "TRUE"


def apply(prev, action, ctx=None):
    got = _step(prev, action, ctx)
    return None if got is None else _cells(prev, got)

def glyph(g, top, left):
    """把 (top,left) 起的 5x5 点阵读成一个 25 位整数（行优先，点亮=1）。越界返回 None。"""
    if top < 0 or left < 0 or top + CELL > len(g) or left + CELL > len(g[0]):
        return None
    v = 0
    for r in range(CELL):
        row = g[top + r]
        for c in range(CELL):
            v = v * 2 + (1 if row[left + c] == INK else 0)
    return v


def slots(g):
    """帧上所有字形槽 [(top, left, 框色, 位图)]，按 (top, left) 排序。

    识别是局部的，所以会捞到「假槽」：跨在两个真槽之间的 5x5 窗口，有时也恰好
    满足「一圈同色 + 内部只有框色与 INK」。真槽互不重叠，所以同一行里从左往右
    贪心丢掉与已收槽重叠的——等宽区间上这个贪心就是「留得最多」的那个解。
    """
    n, m = len(g), len(g[0])
    out = []
    for r in range(1, n - CELL):
        gt, gb = g[r - 1], g[r + CELL]
        for c in range(1, m - CELL):
            fc = gt[c - 1]
            if fc == INK or gt[c + CELL] != fc or gb[c - 1] != fc or gb[c + CELL] != fc:
                continue
            if any(gt[c + j] != fc or gb[c + j] != fc for j in range(CELL)):
                continue
            ok, lit = True, False
            for i in range(CELL):
                row = g[r + i]
                if row[c - 1] != fc or row[c + CELL] != fc:
                    ok = False
                    break
                for j in range(CELL):
                    x = row[c + j]
                    if x == INK:
                        lit = True
                    elif x != fc:
                        ok = False
                        break
                if not ok:
                    break
            if ok and lit:
                out.append((r, c, fc, glyph(g, r, c)))
    kept, last = [], {}
    for r, c, fc, v in sorted(out):
        if r in last and c - last[r] < CELL:
            continue                   # 与同一行已收的槽重叠 —— 真槽不会重叠，这是假槽
        last[r] = c
        kept.append((r, c, fc, v))
    return kept

def board(g):
    """读版面。返回 dict，读不出来返回 None。

    键：ans_row / ans_cols / ans_color / prompt_row / prompt_cols / key_color /
        answer / prompt / legend（[(键位图, [值位图…])]）/ cursor（答题位索引，0 起）。
    """
    key = tuple(map(tuple, g))
    if key in _CACHE:
        return _CACHE[key]
    b = _board(g)
    if len(_CACHE) > 64:
        _CACHE.clear()
    _CACHE[key] = b
    return b


def _rules_of(rows, skip):
    """把 skip 之外的每一行切成规则 [(键色, 键串, 值色, 值串)]。"""
    out = []
    for r in sorted(rows):
        if r in skip:
            continue
        chunk = []
        for cell in rows[r] + [None]:
            if chunk and (cell is None or cell[0] - chunk[-1][0] > GAP_ARROW):
                kc = chunk[0][1]
                ks = [v for _, fc, v in chunk if fc == kc]
                rest = chunk[len(ks):]
                if rest and len({fc for _, fc, _ in rest}) == 1:
                    out.append((kc, tuple(ks), rest[0][1], tuple(v for _, _, v in rest)))
                chunk = []
            if cell is not None:
                chunk.append(cell)
    return out


def _board(g):
    rows = {}
    for r, c, fc, v in slots(g):
        rows.setdefault(r, []).append((c, fc, v))
    if not rows:
        return None
    # 整行同色的两行 = 题面行与答题行。谁是谁不看光标，看颜色在图例里担什么角色：
    # 题面色当过某条规则的键色，答题色只当过值色、从没当过键色。
    solid = [r for r in rows if len({fc for _, fc, _ in rows[r]}) == 1]
    if len(solid) != 2:
        return None
    pick = None
    for prompt_row, ans_row in ((solid[0], solid[1]), (solid[1], solid[0])):
        legend = _rules_of(rows, {prompt_row, ans_row})
        ks = {kc for kc, _, _, _ in legend}
        vs = {vc for _, _, vc, _ in legend}
        kc, ac = rows[prompt_row][0][1], rows[ans_row][0][1]
        if kc in ks and ac in vs and ac not in ks:
            if pick is not None:
                return None                       # 两种指派都说得通 —— 读不出来
            pick = (prompt_row, ans_row, legend, kc, ac)
    if pick is None:
        return None
    prompt_row, ans_row, legend, key_color, ans_color = pick

    ans_cols = [c for c, _, _ in rows[ans_row]]
    # 光标：色 0 的角标框住的是**一整串**字形槽（可以框在图例上，不一定在答题条上）
    cur = [(r, c) for r in range(len(g)) for c in range(len(g[0]))
           if g[r][c] == CURSOR_COLOR and r != HUD_ROW]
    focus, focus_cells = None, None
    if cur:
        r0, r1 = min(r for r, _ in cur), max(r for r, _ in cur)
        c0, c1 = min(c for _, c in cur), max(c for _, c in cur)
        boxed = sorted((r, c) for r in rows for c, _, _ in rows[r]
                       if r0 <= r and r + CELL - 1 <= r1 and c0 <= c and c + CELL - 1 <= c1)
        if boxed:
            focus, focus_cells = boxed[0], boxed
    return {"ans_row": ans_row, "ans_cols": ans_cols, "ans_color": ans_color,
            "prompt_row": prompt_row, "prompt_cols": [c for c, _, _ in rows[prompt_row]],
            "key_color": key_color,
            "answer": [v for _, _, v in rows[ans_row]],
            "prompt": [v for _, _, v in rows[prompt_row]],
            "rules": legend,
            "legend": [(ks, vs) for kc, ks, vc, vs in legend
                       if kc == key_color and vc == ans_color],
            "focus": focus,
            "focus_cells": focus_cells,
            "cursor": (ans_cols.index(focus[1])
                       if focus is not None and focus[0] == ans_row
                       and focus[1] in ans_cols else None)}

def bracket(run):
    """框住整串 run 的角标该占的格子 frozenset[(行, 列)]。run 是 [(行, 列)…]（槽的左上角）。"""
    if not run:
        return None
    r0 = run[0][0]
    c0, c1 = run[0][1], run[-1][1] + CELL - 1
    top, bot = r0 - BRACKET_UP, r0 + BRACKET_DOWN
    out = {(top, c) for c in range(c0, c1 + 1)}
    out |= {(bot, c) for c in range(c0, c1 + 1)}
    out |= {(top + 1, c0), (top + 1, c1), (bot - 1, c0), (bot - 1, c1)}
    return frozenset(out)

def _to_grid(v):
    return [[(v >> (CELL * CELL - 1 - (r * CELL + c))) & 1 for c in range(CELL)] for r in range(CELL)]


def _to_bits(m):
    v = 0
    for row in m:
        for x in row:
            v = v * 2 + x
    return v


def dihedral(v):
    """位图 -> {变换名: 位图}，8 个二面体变换（rot0..rot3，各再配一个左右翻）。"""
    out, cur = {}, _to_grid(v)
    for k in range(4):
        out[f"rot{k}"] = _to_bits(cur)
        out[f"rot{k}+flip"] = _to_bits([[cur[r][CELL - 1 - c] for c in range(CELL)] for r in range(CELL)])
        cur = [[cur[CELL - 1 - c][r] for c in range(CELL)] for r in range(CELL)]
    return out


def congruent(v):
    """v 的二面体等价类（8 个像去重后的 frozenset）——「形状相同、朝向不论」。"""
    return frozenset(dihedral(v).values())


# 字形环上的**形状**只有几条固定序列，一条叫一个「形状族」。已量到三族，每族 7 个形状、循环。
# 每族只记一个代表位图，相位就是它在族里的下标；同一个形状可以有好几个具体环（朝向不同的实例），
# 所以「相位」比「具体环」弱，也比它稳：具体环是**槽**的属性，形状族与相位是**字形**的属性。

    [0x04A92A4, 0x172109D, 0x1D80037, 0x158561F, 0x110476A, 0x17AF415, 0x1B8D63B],
    [0x04FC63F, 0x1F8FD4E, 0x072FE9C, 0x1FADE3F, 0x1F4A5E1, 0x04FD7E4, 0x1E9C72F],

    return None if v is None else _PHASE.get(congruent(v))


def _rewrite(seq, rules, cap):
    """把序列 seq 按 rules（同一个键色、同一个值色的一组 (键串, 值串)）切段改写一次。
    返回所有结果（长度不超过 cap）。"""
    out = set()

    def walk(i, acc):
        if len(acc) > cap:
            return
        if i == len(seq):
            out.add(tuple(acc))
            return
        for ks, vs in rules:
            m = len(ks)
            if i + m > len(seq):
                continue
            if all(seq[i + t] in congruent(ks[t]) for t in range(m)):
                walk(i + m, acc + list(vs))

    walk(0, [])
    return out


def parses(g):
    """题面沿颜色链反复改写，直到变成答题色且正好铺满答题条；返回所有可能的值串
    set[tuple[位图]]。每一步的匹配都是**逐格二面体同余**，不看朝向。"""
    b = board(g)
    if b is None:
        return None
    n = len(b["ans_cols"])
    byk = {}
    for kc, ks, vc, vs in b["rules"]:
        if ks and vs:
            byk.setdefault((kc, vc), []).append((ks, vs))
    out, frontier, seen = set(), {(b["key_color"], tuple(b["prompt"]))}, set()
    for _ in range(4):                       # 颜色链最多走 4 跳
        nxt = set()
        for col, seq in frontier:
            if (col, seq) in seen:
                continue
            seen.add((col, seq))
            if col == b["ans_color"]:
                if len(seq) == n:
                    out.add(seq)
                continue
            for (kc, vc), rules in byk.items():
                if kc != col:
                    continue
                for res in _rewrite(seq, rules, 2 * n):
                    nxt.add((vc, res))
        frontier = nxt
        if not frontier:
            break
    return out


def shapes(g):
    """答题条每一格要的形状（一个二面体等价类）；切法不唯一或读不出来返回 None。

    这是 win_rule / win_prev 共用的判据：题面被切成段，每段换成规则的值串，
    首尾接起来正好铺满答题条；每一格只被规定形状，不规定朝向。
    """
    ps = parses(g)
    if not ps or len(ps) != 1:
        return None
    return [congruent(v) for v in next(iter(ps))]


def _gaps(g):
    """答题条每一格离目标形状还差几下 ACTION1（0..6）；读不出来那一格给 None。
    整块读不出来（图例关的切法不唯一等）返回 None。"""
    want, b = shapes(g), board(g)
    if want is None or b is None or len(want) != len(b["answer"]):
        return None
    out = []
    for v, w in zip(b["answer"], want):
        p = phase(v)
        if p is None:
            out.append(None)
            continue
        fam, i = p
        tgt = [k for k, s in enumerate(SHAPE_FAMILIES[fam]) if congruent(s) == w]
        out.append(None if len(tgt) != 1 else (tgt[0] - i) % len(SHAPE_FAMILIES[fam]))
    return out
