它说什么

玩家走开一格：他原来站的那一格露出他脚下被盖住的那块垫子——色对就是他走上去时那一块的色对（其间点四色小图标、换位会改它）；他脚下本来不是垫子，原格就不露出垫子。

只管方向键、目标格此刻走得进（真的走开了）且不是出口的那一步。脚下是什么由 derive/under.py 沿历史推。

它明确不主张什么

  • 不说露出来的垫子的相位（哪个色在左上）
  • 不说脚下不是垫子时原格露出什么颜色——那一格的颜色不进世界（只进「走不走得进」，而那一格他刚站过，一定走得进）

改版史

  • v1（本轮新写）：起点册子 pad_partner_under_player（只露一块时，脚下是它的同伴）与 underfoot_reveals_floor_vote（按四邻投票猜原格颜色）两条是一帧读法：都在猜一位帧上读不出来的信息。这里换成沿历史推——那一位本来就是历史，不是帧的函数。投票猜地板色那一半不搬（地板色不进世界）。

# Under —— 玩家脚下被盖住的那块垫子（↔ `rule/世界怎么回应/under_revealed.py`）　**身份：定义**

走进一块露着的垫子：它从露着的垫子里消失，记成 `under`；
走开：`under` 里记着的那块垫子回到原格，露出来。走到不是垫子的格上，`under` 清空。

这是这一局唯一的隐藏量。它不在帧上，所以只能这样沿着历史推进——
单看一帧，玩家脚下是不是垫子、是哪一对，**读不出来**。
-/

import Obj.Frame.World

namespace Game

/-- 玩家从原格走到 `t`。 -/
def walk (w : World) (t : Cell) : World :=
  { w with
    me    := t
    pads  := (match w.under with
              | some k => ⟨w.me, k⟩ :: dropPad w.pads t
              | none   => dropPad w.pads t)
    under := padAt w.pads t }

end Game

def scope_(w, action, nw, ctx=None):
    a = read(action)
    if a.kind != "move":
        return "不是方向键"
    s = skip_mark(ctx)
    if s:
        return s
    t = target(w, a)
    if t in w.goal:
        return "走向出口格（换关，下一帧是另一张盘）"
    if t not in w.open:
        return "目标格走不进：玩家没走开"
    if "under" not in (ctx or {}):
        return "没有沿历史推出来的脚下"
    return None


def assert_(w, action, nw, ctx=None):
    u = ctx["under"]
    got = {p.cell: p.pair for p in nw.pads}.get(w.me)
    return "TRUE" if got == u else "FALSE"
