它说什么

按提交（ACTION5）：板上的读序恰好等于面板上那一串 ⟺ 过关（关卡号 +1）。不等时不过关，选中框消失，计数条恰好 +1，别的一格不变。

只管提交；拿不到关卡号（没有 ctx）不管；前一帧读不成不管；关卡号没动而后一帧读不成不管（按观测切，不按本条的预测切）。换了关的那一步不看后一帧 —— 它已经是下一关的盘或终局画面。

它明确不主张

  • 过关之后下一关长什么样 —— 那是 unmodeled/levelup_fresh 管的（它只说计数条和选中）
  • 读序读不出来（板上还有空位 / 环指不到板 / 没有起读板）时会不会过关 —— 这里按「不等」判：不过关
  • 有板没被读到时能不能过关 —— 语料里的过关摆法没有留下没读到的板

改版史

  • v1（本轮重排）：合并册子里的 submit_matches_panel v7（过不过关）与 action5_costs v3（不过关那一路世界怎么变）。两条的论域完全相同（都是 ACTION5），结论各说一半 —— 是同一条规则被拆成了两条。
  • 起读板改成读角标（objects/layout/board.py），读序规则少了「没人指着 / 全被指着取左上」两个分支。
  • 册子 v3→v4→v5 的死因照抄：「先行后列」对不上两排板那一关（e728acac1e14dc8c）；计数吻合不是对应关系的证据。
  • v2（反向测试逼出来的）：v1 的论域按**本条自己的预测**切 —— 预测不过关、后一帧读不成就不管。突变体 M8（面板两排照拼）把过关那一步预测成不过关，后一帧恰是终局画面，于是它在唯一该红的两步上闭嘴、整个突变体没红。改成按观测切：关卡号没动而后一帧读不成才不管。

按提交：读序等于面板（`isGoal`）⟺ 过关；不等时选中消失、计数条 +1、别的一格不变。

def scope_(prev, action, nxt, ctx=None):
    return _scope(action, ctx, unreadable(prev), unreadable(nxt))


def _scope(action, ctx, bad_prev, bad_next):
    kind, _cell = act(action)
    if kind != "submit":
        return "不是提交"
    if not ctx or ctx.get("level_prev") is None or ctx.get("level_next") is None:
        return "拿不到关卡号"
    if bad_prev:
        return bad_prev
    # 后一帧读不读得成，只按**观测**分（关卡号动没动），不按本条自己的预测分。
    # v1 写的是「预测不过关、而后一帧读不成 → 不管」：面板被读错时（突变体 M8），
    # 过关那一步被预测成「不过关」，后一帧是终局画面读不成，于是这一条在唯一该红的地方**闭了嘴**。
    if ctx["level_next"] == ctx["level_prev"] and bad_next:
        return "没换关、后一帧却读不成：" + bad_next
    return None


def assert_(prev, action, nxt, ctx=None):
    if _scope(action, ctx, unreadable(prev), unreadable(nxt)):
        return "NA"
    w = try_world(prev)
    leveled = ctx["level_next"] == ctx["level_prev"] + 1
    if goal(w):
        return "TRUE" if leveled else "FALSE"
    if ctx["level_next"] != ctx["level_prev"]:
        return "FALSE"
    return "TRUE" if try_world(nxt) == replace(w, selected=None, used=w.used + 1) else "FALSE"
