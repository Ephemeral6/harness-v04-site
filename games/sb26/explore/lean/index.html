明写的缺口（摆在最上面：藏起来比红着更坏）

  • 模型在撤销、重开、跨侧点料（语料 0 次）三处说不出话（Res.unknown）：`Unsolvable` 的准确意思是「不经过撤销、重开、跨侧点料就赢不了」。
  • 逐条那一层有 10 条是模型说不出话（撤销 8、会话内重开 2）—— 它们由 Python 那一侧「不进模型」的两条规则对着语料判（undo、reset_restores），不是没人核。
  • 「重来把局面放回开局」这条假设：认证那一段里没有一次中途重开，每关定理用不上它；它只在 Python 规则 reset_restores 上被判过（论域 2、被驳倒 0）—— 没被驳倒不构成证明。
  • 起读板两种读法（角标 / 没被环指着的那块）在这批语料上分不开（见 analysis/Board.txt）。
  • 计数条满 64 之后模型照样 +1：语料里最多用到 49 格，满格那一路没被检验过。

它怎么来的

  • 对象 / 规则 / 分发全是定义：定义 8 条、推论 4 条（Derived 下的定理）、 不进模型 4 条（写明理由，打论域与被驳倒两个数）。Step.lean 0 条定理。
  • 观测只存一份（Obs/Replay.lean）；逐条一层（Obs/Corpus.lean）与每关一层都从它切。
  • 逐条：423 条真实转移，对上 413、对不上 0（内核定理 corpus_no_mismatch）、 说不出话 10（撤销、重开要历史）。与 Python 规则逐条对账：对上 423、对不上 0。
  • 定理 53 条，每条都跟过 #print axioms：53/53，只有 propext / Classical.choice / Quot.sound。
  • 破坏测试 Broken.lean：编不过，错误落在第 [27] 行，标记在第 27 行。
