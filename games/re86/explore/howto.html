在自己电脑上看

双击 web/dist/index.html。每一页的样式、脚本、数据都内联在里面， 不需要起服务、不需要联网。整个 dist/ 文件夹一起拷走或压成 zip 发出去；只拷一页出去是打不开的（页与页之间是相对链接）。

重新生成（顺序不能换）

python run_rules.py --reverse      读数 + 反向测试
python lean2/export_replay.py      观测那一份
python lean2/export_levels.py      每一关 + 逐条
python lean2/verify.py             编译 + 机械核判准 → lean2/readings.json
python web/export.py               页面要摆的每个数（读上面落盘的那几份，读不到就停）
python web/pages.py                生成页面
python web/bundle.py               打包成自包含的 dist/
python web/check_no_logic.py       查前端有没有偷偷自己算世界
