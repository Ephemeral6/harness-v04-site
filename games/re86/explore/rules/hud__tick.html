它说什么

关内每一步 spent 只增 0 或 1、从不减少；换到下一关那一步 spent 归 0。

关内每一步，HUD「已花掉」的格数只涨 0 或 1；换关（非终局）那一步归零。

论域：RESET → notmodel/reset_restarts；终局那一步（WIN）不发新预算，不管

它明确不主张什么

  • 哪一步涨、哪一步不涨——归 notmodel/budget_curve（要本关步数与预算，帧上都没有）
  • 预算花光会怎样：语料里 0 次
