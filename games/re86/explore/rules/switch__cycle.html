它说什么

ACTION5 不改任何东西（几何、颜色、hub 那一格画不画本色），只把选中换到图层次序里上面一层那件（到顶绕回最底；中心在盘外的跳过）。

ACTION5：所有东西一格不动，光标换到**图层次序里高一层**的那件（到顶绕回最底），
包围盒中心在盘外的跳过。

论域：不是 ACTION5 → move/*；换关 / 终局 → goal/level_up

它明确不主张什么

  • 图层次序怎么定的（出生顺序？）——只主张它一关之内不变、ACTION5 按它轮
  • 「中心在盘外的跳过」：语料里候选的中心全在盘内，这一支 0 次被检验
  • 从没被选中过的斜叉 hub 画不画本色：两样都见过，是出生时定的，不主张
  • 斜叉被选中**期间**（hub 压在光标底下，看不见）hub 会不会被清掉：第 2 关那件先画后空、第 4 关那件被推过、换下之后仍画着——跨步看是变了，可每一次变都发生在看不见的那几步里，这一条的逐步判决碰不到它。这一位因此不进 Lean 模型（lean2/Obs/Replay.lean 文件头）

改版史

  • v1 起点册子 a5_cycle_order 用「形状名主键 + 颜色号升序」（11 版）；这里整关跟踪身份之后量出：第 6 关三件（square / plus / cross）的实际轮法是 plus → square → cross，与册子的 square → plus → cross 正好反向，而与「图层从下往上」逐次一致。全部 3 件的关里，读得到图层的那几关没有一次例外（runs/_wb-re86/probe_layers.py）
  • v2 并进撤册的 switch/hub_cleared 的那一半：hub 画不画本色是那件东西自己的，换人不改它（hub_cleared 被第 4 关驳倒 9 次，死因见 analysis/history/rule_retired/README.md）

# Rule/Switch/Cycle —— ACTION5：选中换到图层上面一层那件（对应 `rule/switch/cycle.py`）

`World.pieces` 按图层从下往上排，所以「上面一层」就是下标 +1，到顶绕回 0；
包围盒中心在盘外的跳过。东西一件都不改——这一句在这边**表示不出来**：
`cycle` 只返回一个下标。
-/

import Obj.World

namespace Game

def Piece.onBoard (p : Piece) : Bool :=
  decide (0 ≤ p.cr) && decide (p.cr < 63) && decide (0 ≤ p.cc) && decide (p.cc < 64)

def cycle (s : World) : Nat :=
  let n := s.pieces.length
  let cand := (List.range n).map (fun k => (s.active + k + 1) % n)
  (cand.find? (fun j => j != s.active && ((s.pieces[j]?).map Piece.onBoard).getD false)).getD s.active

end Game
