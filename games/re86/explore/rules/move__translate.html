它说什么

推一下而没撞上挡块时，被选中的那一件整件平移 3 格（上下左右），几何一格不变。

推一下、没撞上挡块：被选中那件**整件平移 3 格**，形状、大小、hub 空不空都不变。

论域：不是推 → 别的组；换关 / 终局那一步 → goal/level_up；撞上挡块 → move/blocked_cross 或 move/blocked_box；颜色 → move/recolor；别的东西动没动 → move/others_stay

它明确不主张什么

  • 不主张颜色不变（碰到色块会变色，归 move/recolor）
  • 不主张盘边会挡：伸出盘外的部分照样平移，只是画不出来（这一条被全部平移步撑着）
  • 斜叉 / 菱形撞挡块会怎样——语料里 0 次，不主张

# Rule/Move/Translate —— 推一下、没撞上挡块：整件平移 3 格（对应 `rule/move/translate.py`）

**定义，不是定理。** 「推一下就平移」是对「推」的定义；把它写成待证的定理等于用它自己证它自己。

论域（`hitsBlock = false`）也在这里：撞上了挡块归 `BlockedCross` / `BlockedBox`，
分发写在 `Step.lean`。
-/

import Obj.World

namespace Game

/-- 平移 (dr, dc) 之后，有没有一格落在挡块上。 -/
def hitsBlock (b : Board) (p : Piece) (dr dc : Int) : Bool :=
  b.blockers.any (fun rc => p.mem (rc.1 - dr) (rc.2 - dc))

/-- 没撞上挡块：整件平移。 -/
def translate (p : Piece) (a : Act) : Piece :=
  p.shift a.delta.1 a.delta.2

end Game
