它说什么

走完这一步后，每个环心都被一件与该环归属色同色的东西盖住，当且仅当这一步过关。

这一步走完，**每个环心都被一件与环同色的东西盖住** ⇔ 过关（关号 +1，最后一关是 WIN）。

论域：RESET → notmodel/reset_restarts；其余每一步都管（两个方向都主张）

它明确不主张什么

  • 环心正好落在斜叉 / 菱形空着的 hub 上算不算盖住：按「不算」写（hub 空着就不是它的格），语料里没撞上
  • 一个环心同时被两件东西压着、一件同色一件不同色：按「有一件同色就算」写，语料分不开

改版史

  • v1 接手册子 all_on_target_levels_up / no_levelup_unless_aligned / wrong_color_cover_no_levelup：三条是同一句 iff 的三个切面（够了就过 / 不够不过 / 颜色不对不过），合成一条两个方向都主张
  • 归属色取**整关口径**：环心一旦被盖住帧上就读不出归属色（册子 no_visible_satisfaction_mark），所以取这一关里第一次读得出的那一帧（环不动、归属色不变，见 board/static）

# Rule/Goal/LevelUp —— 什么算过关（对应 `rule/goal/level_up.py`）

**赢是一个状态的性质**：每个环心都被一件与环同色的东西盖住。写成状态性质，
「这个局面还能不能赢」才有得问（`Proof/Reachable.lean`）。
斜叉 / 菱形空着的 hub 不算盖住（`mem` 里 hub 只在不空时才算它的格）。
-/

import Obj.World

namespace Game

def isGoal (b : Board) (s : World) : Bool :=
  b.rings.all (fun g => s.pieces.any (fun p => p.mem g.r g.c && p.color == g.owner))

end Game
