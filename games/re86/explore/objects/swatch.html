没有色块这两种结局是同一个世界说出的两句话。M06（从不变色）打红 recolor 56 条。

它是什么

`Swatch` —— 色块：一圈色 2 的方框，里面一整块纯色。

    top left   方框外沿左上角（可以在盘外：框被盘边裁掉一截时照样是框）
    size       外沿边长。实测两种：6（内部 4×4）与 5（内部 3×3）。**不写死**
    color      内部那块的颜色

## 为什么删不掉它

一件东西平移之后只要有一格落进某个色块**整个框那一片**（含色 2 的框边），
它就整件变成那个色块的颜色（规则 `move/recolor_on_swatch`）。
抹掉它，「这一步变色」和「这一步不变色」分不开——而通关要同色，改色是唯一的手段。

# Obj/Board/Swatch —— 色块（对应 `objects/board/swatch.py`）

外沿左上角 + 外沿边长 + 内部颜色。「整个框那一片」= 外沿围起来的正方形（含框边）。
-/

namespace Game

structure Swatch where
  top   : Int
  left  : Int
  size  : Int
  color : Nat
  deriving DecidableEq, Repr

/-- (r, c) 落在整个框那一片里。 -/
def Swatch.inArea (s : Swatch) (r c : Int) : Bool :=
  decide (s.top ≤ r) && decide (r < s.top + s.size) && decide (s.left ≤ c) && decide (c < s.left + s.size)

end Game
