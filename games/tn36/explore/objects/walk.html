它是什么

一串指令 → 件走完停在哪、途经哪几格。组合自：`piece`（起点的形）+ `layout.board`（行列、墙、记号）。

## 一条指令做不了就跳过，其余照走

每条指令先算出「做了之后的形」，那块形盖住的格只要有一格出了盘或是墙，
**这一条就不做**（件留在原样），接着做下一条。

    N / S / W / E   平移一格
    GROW            倍数 ×2，左上角不动
    SHRINK          倍数 ÷2，左上角不动；倍数是奇数时做不了
    ROT             只换缺口朝向：南↔东、北↔西（对合）；左上角与倍数不动
    NOP             什么都不做

记号格**不挡路**。第一版读成「记号格像墙一样挡路」，后来换掉了（理由见 `derive/outcome.py`）；
本批语料里踩上记号格的交卷都另有作废的理由，挡不挡路这批语料分不开（`analysis/gaps.txt` G9）。

「跳过」与「整道作废」两种读法的分界见规则 `piece_follows_program` 的改版史。

# Walk —— 一串指令 → 件走完停在哪。对应 `derive/walk.py`（复合概念：件 + 盘）。

每条指令先算出做了之后的形；那块形盖住的格只要有一格出了盘或是墙，**这一条就跳过**，接着做下一条。
平移一格 / 放大 ×2（左上角不动）/ 缩小 ÷2（奇数倍做不了）/ 旋转（南↔东、北↔西）/ 无操作。
-/
import Obj.Board.Board
import Obj.Panel.Toolbox

namespace Game

def rotNotch : Notch → Notch
  | .S => .E
  | .E => .S
  | .N => .W
  | .W => .N

/-- 这一条指令做了之后的形；做不了给 `none`。往北 / 往西走出盘外同样给 `none`（`Nat` 没有负数）。 -/
def Form.apply (f : Form) : Op → Option Form
  | .N      => if f.cell.r = 0 then none else some { f with cell := ⟨f.cell.r - 1, f.cell.c⟩ }
  | .S      => some { f with cell := ⟨f.cell.r + 1, f.cell.c⟩ }
  | .W      => if f.cell.c = 0 then none else some { f with cell := ⟨f.cell.r, f.cell.c - 1⟩ }
  | .E      => some { f with cell := ⟨f.cell.r, f.cell.c + 1⟩ }
  | .GROW   => some { f with scale := f.scale * 2 }
  | .SHRINK => if f.scale % 2 = 0 then some { f with scale := f.scale / 2 } else none
  | .ROT    => some { f with notch := rotNotch f.notch }
  | .NOP    => some f

def Board.fits (b : Board) (f : Form) : Bool :=
  f.footprint.all fun x => b.inside x && !(b.walls.contains x)

def walk (b : Board) : Form → List Op → Form
  | f, []        => f
  | f, op :: ops =>
      match f.apply op with
      | some g => if b.fits g then walk b g ops else walk b f ops
      | none   => walk b f ops

end Game

"""一串指令 → 件走完停在哪、途经哪几格。组合自：`piece`（起点的形）+ `layout.board`（行列、墙、记号）。

## 一条指令做不了就跳过，其余照走

每条指令先算出「做了之后的形」，那块形盖住的格只要有一格出了盘或是墙，
**这一条就不做**（件留在原样），接着做下一条。

    N / S / W / E   平移一格
    GROW            倍数 ×2，左上角不动
    SHRINK          倍数 ÷2，左上角不动；倍数是奇数时做不了
    ROT             只换缺口朝向：南↔东、北↔西（对合）；左上角与倍数不动
    NOP             什么都不做

记号格**不挡路**。第一版读成「记号格像墙一样挡路」，后来换掉了（理由见 `derive/outcome.py`）；
本批语料里踩上记号格的交卷都另有作废的理由，挡不挡路这批语料分不开（`analysis/gaps.txt` G9）。

「跳过」与「整道作废」两种读法的分界见规则 `piece_follows_program` 的改版史。
"""
from __future__ import annotations

from objects import Cell, Form

from .program import TRANSLATIONS

ROT_NOTCH = {"S": "E", "E": "S", "N": "W", "W": "N"}


def _next(form, op):
    """这一条指令做了之后的形；做不了（奇数倍还要缩）返回 None。"""
    if op in TRANSLATIONS:
        dr, dc = TRANSLATIONS[op]
        return Form(Cell(form.cell.row + dr, form.cell.col + dc), form.scale, form.notch)
    if op == "GROW":
        return Form(form.cell, form.scale * 2, form.notch)
    if op == "SHRINK":
        return Form(form.cell, form.scale // 2, form.notch) if form.scale % 2 == 0 else None
    if op == "ROT":
        return Form(form.cell, form.scale, ROT_NOTCH[form.notch])
    if op == "NOP":
        return form
    return None


def walk(board, piece, ops):
    """返回 (终点的形, 每一条**做成了**的指令之后的形)。"""
    blocked = board.walls
    form, trail = piece, []
    for op in ops:
        nxt = _next(form, op)
        if nxt is None:
            continue
        if any(not board.inside(c) or c in blocked for c in nxt.footprint()):
            continue
        if nxt != form:
            trail.append(nxt)
        form = nxt
    return form, trail
