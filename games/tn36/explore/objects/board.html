它是什么

`Board` —— 盘：一关之内**不会动**的那部分。

    rows, cols  几行几列格（第 0 关 8×9，别的关 7×7）
    walls       挡路的格（色 6 占过半）
    marks       带记号的格（色 14 竖条 + 色 12/13 纹）。整局只在一块盘上出现过，一行两格
    socket      插槽围出来的空腔：一块 `Form`（件要变成和它一模一样才算填满）

花格（`Pads`）不在这里：它们也是盘上画着的、不会动的东西，但**件压在上面时帧上看不见**，
于是「这一帧看得见哪几格花格」会随件挪动而变。那一位单独成一个字段，理由写在 `pads.py`。

from __future__ import annotations

from dataclasses import dataclass

from ..geometry.form import Form


@dataclass(frozen=True, order=True)
class Board:
    rows: int
    cols: int
    walls: frozenset
    marks: frozenset
    socket: Form

    def inside(self, cell) -> bool:
        return 0 <= cell.row < self.rows and 0 <= cell.col < self.cols
