它说什么

按大圆交卷、程序算出来的终点的形（格、倍数、缺口）与插槽空腔相同 ⇒ 这一下过关；反过来，关卡前进（或整局打完）的那一下，一定是这样一次交卷。

过关当且仅当：按大圆交卷，而程序算出来的终点和插槽空腔一模一样。

论域：什么时候它不管、交给谁

开口的只有两类步：点中大圆且算出来填满的那一下（正向），以及上游说关卡前进 / 整局打完的那一下（反向）。RESET（关卡号往回跳）不是过关，归 `说了但不进模型/reset_restarts`。别的步不开口：它们「没过关」这一半由 `一步怎么走/` 的两条逐格核（下一帧还是同一关的版面）。

它明确不主张什么

不主张过关之后下一关长什么样（那是下一关的版面，帧上只看得到结果，模型不描述）。不主张最后一关打完那一帧画成什么样（件进了插槽、记号那一行亮成光带——那一帧读不成世界）。

def scope_(w, action, nw, ctx):
    if is_reset(action):
        return "RESET 不是过关 → 说了但不进模型/reset_restarts"
    if level_changed(ctx) and (ctx.get("level_next", 0) > ctx.get("level", 0)
                               or ctx.get("state_next") == "WIN"):
        return None
    if target(w, action) == ("disc",) and outcome(w)[0] == "win":
        return None
    return "既不是填满的交卷，也不是关卡前进的那一步"


def assert_(w, action, nw, ctx):
    fit = target(w, action) == ("disc",) and outcome(w)[0] == "win"
    advanced = (ctx.get("level_next", 0) > ctx.get("level", 0)) or ctx.get("state_next") == "WIN"
    return fit == advanced
