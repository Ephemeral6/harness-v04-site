它说什么

同一关之内的每一下点击：点中大圆而算出来不填满空腔时，面板读成程序（derive/program）、件逐条走、做不了的那一条跳过（derive/walk）；终点盖住的格全是看得见的花格 → 件挪过去，否则整道作废、件一格不挪。没点中大圆 → 件与看得见的花格都不动。

关内每一下点击：点中大圆而不过关 → 件照程序走到花格上，或整道作废一格不挪；没点中大圆 → 件与花格一格不动。

论域：什么时候它不管、交给谁

只管关内的点击。点中大圆且算出来填满空腔（过关）→ `什么算赢/fit_clears_level`；RESET → `说了但不进模型/reset_restarts`；面板归 `一步怎么走/panel_follows_clicks`，顶栏归 `世界怎么回应/counter_pays`，版面归 `世界怎么回应/layout_stays`。

它明确不主张什么

不主张件离开的那一格露出什么：件压着的格帧上读不出是不是花格，只核「露出来的要么是底色、要么是一格花格」。不主张放大/缩小/旋转做不了时的对照（语料里没有一道这样的程序撞墙而不因别的理由作废）。不主张记号盘上「连四 + 少于三种」这一读法比另两种读法对——三种在本批语料上判决相同，分辨实验在 analysis/gaps.txt G9。

改版史

  1. v1（submit_runs_program）：由起点册子 disc_runs_program（v14）、offpad_end_voids（v4）、allblank_voids_program（v3）、piece_footprint_blocks（v3）、four_in_a_row_voids、few_ops_and_dwell_voids、blank_slot_is_nop 七条合成——那七条是「交卷」被论域切成七片、每片各说一半。同时换掉三处读法：（一）缩放/旋转程序也按「做不了就跳过」（本批唯一一道撞墙的缩放程序 seq 38 在两种读法下都作废，取更少的一种）；（二）「整列全暗」照常执行还是让整道作废，改由底栏读：底栏给了「无操作」那个框就照常（第 4 关），没给就作废（seq 140/161）；（三）记号盘改成「光带那一行只许停一格」+「记号格挡路」，替掉册子的「连四作废 + 码少于三种且久留」。
  2. v2（改名 piece_follows_program）：与面板那条同一次改，按对象管——件在每一下关内点击上怎么变都归这一条，没点中大圆就是「不动」。v1 只管交卷那一下，点面板时件与花格没人管。v1 源码在 analysis/history/rule_v1/。
  3. v3：记号盘的读法从「记号挡路 + 光带那一行只许停一格」换成「连四作废 + 用到的指令少于三种作废」（derive/outcome.py）。本批语料上两种都 14/14（alt_readings.py）；换的理由：后者条件更少，且前者对「件在 (6,2) 交六个北」给出过关，而起点册子记着另一次跑里一道连六的程序在这块盘上作废——那条核不了，只用来在分不开的读法之间挑。

import Obj.Compose.Outcome

namespace Game

def pieceAfter (L : Layout) (w : World) : Option Target → Form
  | some .disc =>
      match outcome L w with
      | .move f => f
      | _       => w.piece
  | _ => w.piece

end Game

def scope_(w, action, nw, ctx):
    if xy(action) is None:
        return "不是点击 → RESET 归 说了但不进模型/reset_restarts"
    if level_changed(ctx):
        return "这一步换了关 → 什么算赢/fit_clears_level"
    if target(w, action) == ("disc",) and outcome(w)[0] == "win":
        return "算出来填满空腔（过关）→ 什么算赢/fit_clears_level"
    return None


def assert_(w, action, nw, ctx):
    if target(w, action) != ("disc",):
        return nw.piece == w.piece and nw.pads == w.pads
    kind, got = outcome(w)
    if kind == "void":
        return nw.piece == w.piece and nw.pads == w.pads
    if nw.piece != got:
        return False
    must = w.pads.cells - got.footprint()
    may = must | w.piece.footprint()
    return must <= nw.pads.cells <= may
