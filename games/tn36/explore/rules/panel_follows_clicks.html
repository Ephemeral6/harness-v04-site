它说什么

同一关之内的每一下点击：点中面板某个件的命中盒 → 那一个件在亮与暗之间翻一下、别的件不动；点中大圆或什么都没点中 → 面板一个件都不动。

关内每一下点击：点中面板的某个件 → 只有那一个件翻亮暗；没点中面板的件 → 面板一格不动。

论域：什么时候它不管、交给谁

只管关内的点击（ACTION6）。RESET 归 `说了但不进模型/reset_restarts`；换关 / 打完整局那一步下一帧是另一关，归 `什么算赢/fit_clears_level`。件与花格归 `一步怎么走/piece_follows_program`，顶栏归 `世界怎么回应/counter_pays`，版面归 `世界怎么回应/layout_stays`。

它明确不主张什么

不主张命中盒的边界：本批语料每一下都点在件的正中，盒比件大一圈这件事来自起点册子，一次都没被检验过（反向测试 M12 把盒收窄到正中一列，照样全绿）。「什么都没点中」那一支语料里 0 次——它在这里是为了让命中盒读错时有人喊（M13）。

改版史

  1. v1（toggle_flips_one）：由起点册子 panel_click_toggles / top_click_toggles / stem_click_toggles 合成，只管「点中面板件」那一下。
  2. v2（改名 panel_follows_clicks）：反向测试把横条的命中盒整个挪出画面（M13），读数一格没红——点横条变成「什么都没点中」，v1 于是闭嘴，而面板明明变了，**没有任何规则说面板不许变**。所以改成按对象管：面板这个对象在每一下关内点击上怎么变，全归这一条，点中别处就是「不动」。v1 的源码留在 analysis/history/rule_v1/。

def scope_(w, action, nw, ctx):
    if xy(action) is None:
        return "不是点击 → RESET 归 说了但不进模型/reset_restarts"
    if level_changed(ctx):
        return "这一步换了关：下一帧是另一关的版面 → 什么算赢/fit_clears_level"
    return None


def assert_(w, action, nw, ctx):
    tgt = target(w, action)
    if tgt is None or tgt == ("disc",):
        return nw.panel == w.panel
    want = Panel(w.panel.groups, w.panel.slots, w.panel.dark ^ {tgt})
    return nw.panel == want
