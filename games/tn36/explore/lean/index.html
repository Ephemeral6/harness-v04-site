一、规则层在这批语料上**没被检验过**的分支（语料里 0 次）
  G1 点击没点中任何东西（空白、底栏的框、左半边）：0 次。panel_follows_clicks / piece_follows_program 对它主张「不动」，
     从没被驳倒过也从没被证实过。分辨实验：点一下盘上的空白格。
  G2 点底栏的框：0 次。起点册子说点框会换掉左半边的示范图与对照面板——那些像素在 scenery 指纹里，
     layout_stays 主张它们一关之内不变，真点一下框这一条会当场判错（那是对的：它会逼出一条「点框」的规则）。
  G3 关内 RESET：0 次（唯一一次 RESET 在整局打完之后）。关内 RESET 之后顶栏节奏的 k 从几数、面板与件回到哪，都不知道。
  G4 交卷时有一槽没写码 / 码不在密码本里：各 0 次。derive/program 主张整道作废，没被检验。
  G5 件以大于 1 倍停在花格上、终点就是起点：各 0 次。
  G6 放大被墙挡、奇数倍还要缩：各 0 次（「做不了就跳过」只在平移上被检验过：N 被挡 11 次、S 3 次、E 2 次、W 1 次）。
  G7 旋转：只见过「东→南」（2 次，同一道程序在两段语料里各交一次）。对合（南↔东、北↔西）与顺时针 90° 在这一支上一样，
     反向测试 M11 印证：换成顺转一格不红。分辨实验：第 4 关把 ROT 放在件缺口朝北时交一次。
  G8 顶栏见底：最少还剩 23 格，从没见底。

二、读法分不开（两种以上说法在这批语料上判决完全相同）
  G9 记号盘（关号 6）上「作废」的三种读法（python alt_readings.py → analysis/alt_readings.txt）：
     C 现行：「同一条指令连四作废」+「用到的指令少于三种作废」，记号格不挡路。
     B 起点册子：「连四作废」+「码少于三种 **且** 在记号行停两格以上作废」，记号格不挡路。
     A 第一版（已换掉）：「记号格像墙一样挡路」+「记号所在那一行最多停一格」。
     本批语料 14 次记号盘交卷（两段合计；2 次因全暗槽不合法先作废）三种读法都 14/14。
     为什么取 C：条件最少；A 对「件在 (6,2) 交六个北」给出「过关」，而起点册子的改版史记着另一次跑里一道「连六」
     的程序在这块盘上作废——那条记录不在本批语料里、核不了，只用来在分不开的读法之间挑，**不当证据**。
     分辨实验（从语料里出现过的局面出发枚举 4^6 道六步平移程序，机器列出来的）：
       B 对 C：件在 (6,2) 交 N N W N N W 或 N W N N N W —— B 说件挪到花格 (2,0)，C 说作废。只有这 2 道。
       A 对 C：件在 (6,2) 交 N N N N N N —— A 说过关，C 说作废；件在 (5,5) 交 E N N N W N —— A 作废，C 挪件。
  G10 「整列全暗」（无操作）在第 6 关让整道作废：这一版读成「底栏没给这个指令」（第 6 关底栏只有四个方向）。
     另一种读法「记号盘上只许平移」判决一样。分辨实验：在第 5 关（四方向底栏、没有记号）交一道带全暗槽的程序。
  G11 付费节奏：第 0–4 关每下掉一格、第 5–6 关每两下掉一格，是一张按关号记的语料事实表（counter_pays.RATE）；
     「本关已走几步的奇偶」帧上读不出来，由 meta 数（ctx.k）。这是规则读了一位帧上没有的信息，写在明处：
     换一张卡第一次进一个新关，这张表可能先错一次。
  G12 命中盒的边界：每一下点击都在件的正中。盒比件大一圈（横条上下各一行、左右各两列）来自起点册子，
     反向测试 M12 把盒收窄到正中一列照样全绿。
