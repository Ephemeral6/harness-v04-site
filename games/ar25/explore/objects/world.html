为什么删不掉它（analysis/）

targets（World.targets）—— 目标块

1. 它记什么：这一关的目标块集合。帧上的读法：中心格是目标色（目标画在地板上，压不没，永远从中心透出来）。
2. 谁读它：rule/win/level_clear（derive/cover：每一块目标都要被盖住）；
   derive/band_cells（带在目标处让位）⇒ push_moves_selected 推带时的新占位、click_selects 的点中判断。
   解析画回去时读它（中心格）。
3. 消融（第 5 轮）：6 处判决变了。数少的原因：抹成第 0 关那一组目标后，
   多数步上「盖没盖满」照样是「没满」，只有过关那几步和带让位的几步会变。
4. 分离表：**分不开**（每一份都是）。它关内恒定，换关时别的字段也全变。

**欠账（明写）**：一对「只差目标」的世界在一次通关的语料里造不出来——目标是关卡给的，
玩家动不了它。能分开的只有跨局的实验（同一关换一组目标），这不是这批语料或这个玩家能做的。
它留着的理由是规则那一侧：没有它，「这一关赢了」说不出来（level_clear 的判据就是 targets ⊆ 盖住的块）。

形式化那一边把它搬进一个 `step` 碰不到的结构（关卡的盘，不是状态的字段）：
「走一步目标不变」于是不用证——**表示不出来**。


frozen（World.frozen）—— 画成「推不动」的那几条线

1. 它记什么：哪几条带的中心格画成实心带色（推不动），而不是底色（能推）。
   第 2 轮从 Band.fixed 拆出来：那一位在带**被选中时读不出**（中心格全是标记色），
   挂在带上会让「同一条带选中前后是不是同一件」跟着变。
2. 谁读它：derive/move —— 推一条画成推不动的带，返回「说不准」（第 5 轮补上的一支，
   之前 move 让它照样走，规则少了一支）；于是 push_moves_selected / push_costs_one / level_clear
   的论域都读它。解析画回去时读它（带块的中心格）。
3. 消融（第 5 轮）：9 处判决变了（全是「这条带被当成推不动 ⇒ 推它说不准」，读数上是 TRUE → NA）。
   第 4 轮（补那一支之前）是 2 处——那 2 处来自 move 把 frozen 跟着带搬家，属于「跟着搬」不是「在用」。
4. 分离表：分不开（第 1–5 轮都是）。函数依赖 frozen ← targets 冲突 0（8 组）：关内恒定。

**欠账（明写）**：这一位在这批语料里**没有一处见证它管事**——第 0 关那条带画成推不动，
而那一关 15 步全推物件，**从没人点过那条带**。「它推不动」这句话一次都没被检验过。
分开「①它不管事（只是颜色）」与「③语料分不开」的那一步实验：
    第 0 关开局点那条带（ACTION6 点在 (col 10) 的任一块上），再按一下 ACTION3 / ACTION4。
    动了 ⇒ frozen 只是颜色，该删；没动而计数带不走 ⇒ 它是一条真规则（blocked_push_free 的论域就有了）。
那一步做之前，它**留着**（删它就等于替世界回答了一个没问过的问题）。


sel（World.sel）—— 被选中的是哪一件

1. 它记什么：在规范次序（带在前按线、物件在后按左上角）里，被选中那一件的下标。**是引用，不是值**：
   只许判相等、取对应那一件，不许比大小做算术。
   帧上的读法：中心格是标记色的块 == 某一件露在目标外的全部块；零标记时 == 唯一一件整片压在目标上的。
2. 谁读它：rule/move/push_moves_selected（走的是被选中那一件）、rule/move/click_selects（点完之后它换成点中那件）、
   rule/budget/push_costs_one / rule/win/level_clear（论域要先算推完的世界）。解析画回去时读它（标记穿透所有层）。
3. 消融（第 5 轮）：421 处判决变了。
4. 分离表：唯一一个**不投影**就分得开的字段（见证第 33 / 35 帧：一次点击，只换了选中）。

第 2 轮那一刀（拆）：第 1 轮它存的是被选中那一件的**值**，于是一推，sel 与 pieces（或 bands）一起变，
两个字段谁也分不开；拆成引用之后，投影掉 used，pieces 与 bands 立刻有了见证（field_split.txt 第 2 份）。

读不出来的那一帧：seq 253 next（WIN 之后那一帧）两件物件都整片压在目标上、零标记，
选中的是哪一件帧上没有 —— 解析抛，meta 说 state=WIN，归 (a) 终局画面。
这是全语料唯一一处；它说明「零标记时唯一一件整片压在目标上」**不是**对所有局面都成立的读法，
只是在可玩的局面里成立（能玩的局面里，赢之前总有一件没盖满）。


used（World.used）—— 计数带已用掉几格

1. 它记什么：最后一列 64 格，自上而下用掉了几格（「不是目标色」的前缀长度）。换关清零。
2. 谁读它：rule/budget/push_costs_one（推一下 +1，点一下 +0）。别的规则一条都不读它。
3. 消融（第 5 轮）：187 处判决变了（全在 push_costs_one）。
4. 分离表：**分不开**（每一份都是）。函数依赖 used ← (targets, pieces, bands, sel) 冲突 0（253 组）：
   这一批语料里没有两个世界「盘面一模一样而用掉的格数不同」。

**欠账（明写）**：语料里没有「只差 used」的那一对。能造出那一对的实验：
    推一下再推回来（例如 ACTION4 接 ACTION3），盘面回到原样而 used 多 2。
那一对就是「抹掉 used 之后分不开」的见证。在那之前，它靠的是规则那一侧的读数（消融 187 处）
与游戏本身的约束（用满 64 格会怎样，这一批语料没到过：最多用到 53 格，第 5 关）。

填充色（原 World.fill）第 5 轮删掉：消融 0 处判决变化、一条规则都点不出、fill ← (targets, used) 冲突 0。
删掉的代价：计数带填充格是哪一种颜色没人认领（只认「不是目标色」）。
