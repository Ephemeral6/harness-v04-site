它说什么

ACTION5 放一发水：水从每颗球（以及件里嵌着的记号）往「下」出发，按落/沿面/射流/爬四种走法走（`derive/flow.py`）；这一步过关，当且仅当每个杯口都被某个水头走进去过，而且没有一个水头在盘里落空（停在墙上、杯壁上、或积在件上；从盘的边缘流出去的不算）。

它明确不主张什么

不说没过关那一发之后选中谁（归 `说了但不进模型/handoff_goes_to_nearest`）；不说「本关第 5 发必死」（归 `说了但不进模型/fifth_fire_in_a_level_kills`）；射流横穿水柱这一种情形不表态（模型说不出话）。

论域：只管 ACTION5。水流模型说不出话（射流横穿湿格 / 读不出方向）时不管。

# FireWins —— 一发水过关 ⟺ 水流模型说每个杯口都喂到、没有落空（对应 `rule/什么算赢什么算砸/fire_wins_iff_all_mouths_fed.py`）

**这是「赢」的定义**，不是一条待证的定理。

没过关的那一发：**模型说不出话**。理由写在明处——没过关的一发之后，选中件有时换给别的件
（交棒），有时不换；什么时候换没读出来（`rule/说了但不进模型/handoff_goes_to_nearest.py`）。
编一个「不换」出来比说「不知道」更糟。
-/
import Obj.Composite.Flow

namespace Game

/-- 一发水的三种结果。 -/
inductive Fire where
  | won
  | silent
deriving DecidableEq, Repr

def fireStep (b : Board) (w : World) : Fire :=
  match fireOutcome b w with
  | some true => .won
  | _ => .silent

end Game
