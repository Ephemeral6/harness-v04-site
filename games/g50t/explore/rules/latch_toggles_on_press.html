"""闩车：它的按钮这一步被压下（上升沿）就在家和前一格之间翻一次；松开不动，压着不放也不动。"""
from __future__ import annotations

from derive.cells import occupied
from derive.track import match, tracks
from objects.pieces.cart import KIND, LATCH
from rule._common import MOVE_ACTIONS, common_skip

CLAIM = "闩车：按钮每被压下一次，在家和前一格之间翻一次；松开、按住都不动。轨道再长也只用这两格。"

SCOPE_NOTE = ("只管 ACTION1..4（ACTION5 归 switch_rewinds_carts）。场上没有闩车不管；"
              "车对不上开局那几条轨道不管。")

NOT_CLAIMED = "不说翻过去那一格上站着活物会怎样（语料里没发生过）。"

HISTORY = [
    "起点册子 cart_shifts_on_press 的色 11 那一支：v4 只敢说「按一下挪 1 格，方向不定」，"
    "因为「车此刻在家还是在前一格」帧上读不出。这一版把家从开局那一帧读出来（derive.track），"
    "方向就定了：在家就去前一格，在前一格就回家。v8 之后的实测（环替人连按两次，车回家）正是这一句。",
]

EVIDENCE = ["019a2f5f804790d8", "dafe0ff56ea9d494", "fcef001bb505abd5", "4069e2eb200a9612"]


def scope_(prev, action, nxt, ctx):
    s = common_skip(prev, nxt, ctx)
    if s:
        return s
    if action not in MOVE_ACTIONS:
        return "不是方向键"
    if ctx.get("hist") is None:
        return "这一关的历史不全"
    ts = tracks(ctx["hist"].start(prev))
    if not any(KIND.get(t.color) == LATCH for t in ts):
        return "场上没有闩车"
    if match(ts, prev) is None or match(ts, nxt) is None:
        return "车对不上开局的轨道"
    return None


def assert_(prev, action, nxt, ctx):
    ts = tracks(ctx["hist"].start(prev))
    a, b = match(ts, prev), match(ts, nxt)
    o0, o1 = occupied(prev), occupied(nxt)
    for t in ts:
        if KIND.get(t.color) != LATCH:
            continue
        want = t.other(a[t]) if (t.button in o1 and t.button not in o0) else a[t]
        if b[t] != want:
            return False
    return True
