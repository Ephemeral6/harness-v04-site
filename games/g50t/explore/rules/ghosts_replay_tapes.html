它说什么

替身 = 之前每一盘的录像：从起点格起每一步放一个录下的动作（只录棋子真挪了窝的那几下），进不去就原地但照样消耗；放完永远停住；和棋子一样过传送门。

论域：只管 ACTION1..4（换一盘那一步替身全收回起点，归 switch_restarts_round）。需要这一关此前的历史（带子在历史里，帧上读不出）；历史不全（这一关里有读不成的帧）就不管。

它明确不主张什么

不说两个替身叠在一格时画出来的是哪一个（按格比，叠着的只算一格）；不说替身和环叠在一格时谁在上面（语料里没发生过）。

改版史

  • 起点册子 ghost_follows_me v3 只敢说「每个替身每步至多平移一格或过门」——因为带子是隐藏状态、单条转移看不见。这一版把历史交给规则（derive.history），于是能说落在哪一格，不再是一个范围。
  • 「只录挪了窝的那几下」是这一版第一次跑就被逼出来的：第一盘开头撞墙的 U / L / R 不进带子，照全部动作录的话替身第一步就往墙上撞、和观测差一格（seq 6）。
  • 起点册子 ghost_respects_blocking（替身只站在进得去的格上）被这一条收编：替身只在 enterable 的时候挪，它的拒绝集（替身站进墙 / 车）包含在这一条里。没有另写成 Lean 推论。

def scope_(prev, action, nxt, ctx):
    s = common_skip(prev, nxt, ctx)
    if s:
        return s
    if action not in ("ACTION1", "ACTION2", "ACTION3", "ACTION4"):
        return "不是方向键"
    if ctx.get("hist") is None:
        return "这一关的历史不全"
    if not ctx["hist"].tapes(prev) and not prev.ghosts and not nxt.ghosts:
        return "场上没有替身"
    return None


def assert_(prev, action, nxt, ctx):
    pos = ctx["hist"].ghosts_after(prev, action, nxt)
    seen = set(pos) - {nxt.me}
    return seen == set(nxt.ghosts)
