它说什么

方向键：目标格进得去（地形不是墙、上面没有车）就挪过去，进不去就原地不动。替身、环不挡棋子。

论域：只管 ACTION1..4。目标格是传送门 → 归 portal_needs_rising_edge；换关那一步（走进终点格）→ 归 goal_is_levelup；读不成世界的帧不管。

不说棋子能不能和环叠在一格（语料里棋子从没走进过环所在的格）；不说目标格出了格网会怎样（边上一圈都是墙）。

def scope_(prev, action, nxt, ctx):
    s = common_skip(prev, nxt, ctx)
    if s:
        return s
    if action not in MOVE_ACTIONS:
        return "不是方向键"
    if prev.at(target(prev, action)) in ("A", "B", "F"):
        return "目标格是传送门（归 portal_needs_rising_edge）"
    return None


def assert_(prev, action, nxt, ctx):
    t = target(prev, action)
    want = t if enterable(prev, t) else prev.me
    return nxt.me == want
