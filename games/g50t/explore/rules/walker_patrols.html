它说什么

环：棋子挪窝它才走一格；直走 > 唯一的侧路 > 掉头；棋子没挪它不动；它落脚那格同一步被车挪进来就被压掉。

论域：看全部动作，ACTION5 除外（换一盘把环放回起点，归 switch_restarts_round）。场上没有环不管；需要历史（朝向是它上一次挪动的方向，帧上读不出：环的图案四个朝向逐像素一样）。走到岔路口（直走不通、两侧都通）不管——语料里一次都没有，规则不替它编一个偏好。

它明确不主张什么

不说岔路口怎么选；不说环能不能和棋子 / 替身叠在一格；不说被压掉之后会不会自己回来（换一盘 / RESET 才放回）。

改版史

  • 起点册子里关于环的四条（walker_walks_alone v5、walker_steps_when_i_step、walker_enters_only_free、walker_dies_only_to_moving_cart）各说一半：一步至多一格 / 节拍跟着棋子 / 只进通格 / 不动的车压不死它。那四条都不敢说去哪一格，因为朝向读不出来。朝向是历史里读得出来的（上一次挪动的方向），把历史交给规则之后，四条合成一条、说到具体哪一格。

# walker_patrols（`rule/替身与环/walker_patrols.py`）—— **定义**

环只在棋子挪了窝的那一步走：直走 > 唯一的侧路 > 掉头 > 原地。
岔路口（直走不通、两侧都通）Python 那边闭嘴；这里**选不出就原地**——
那一支在语料里一次都没走到，模型在那里说的话没有被检验过（写在明处）。
被压掉那一半（落脚那格同一步被车挪进来）在 `Step` 里接上，因为它要等车挪完。
-/
import Obj.Derive.Cells

namespace G50t

def sides : Dir → List Dir
  | .up | .down => [.left, .right]
  | .left | .right => [.up, .down]

def canGo (b : Board) (carts : List Cell) (w : Cell) (d : Dir) : Bool :=
  match w.go d with
  | some y => enterable b carts y
  | none => false

/-- 环这一步朝哪走；`none` = 原地。 -/
def walkerChoice (b : Board) (carts : List Cell) (w : Cell) : Option Dir → Option Dir
  | some h =>
    if canGo b carts w h then some h else
    match (sides h).filter (canGo b carts w) with
    | [d] => some d
    | [] => if canGo b carts w h.back then some h.back else none
    | _ => none
  | none =>
    match [Dir.up, Dir.down, Dir.left, Dir.right].filter (canGo b carts w) with
    | [d] => some d
    | _ => none

def walkerPatrols (b : Board) (carts : List Cell) (w : Option Cell) (h : Option Dir) :
    Option Cell × Option Dir :=
  match w with
  | none => (none, h)
  | some x =>
    match walkerChoice b carts x h with
    | some d => ((x.go d).orElse (fun _ => some x), some d)
    | none => (some x, h)

end G50t

DIRS = ((-1, 0), (1, 0), (0, -1), (0, 1))


def choice(w, heading):
    """环这一步想去哪（单位位移）；原地返回 (0, 0)；岔路口返回 None。"""
    def ok(d):
        return enterable(w, w.walker + _delta(d))
    if heading is not None and ok(heading):
        return heading
    back = (-heading[0], -heading[1]) if heading else None
    side = [d for d in DIRS if d != heading and d != back and ok(d)]
    if len(side) == 1:
        return side[0]
    if len(side) > 1:
        return None
    if back is not None and ok(back):
        return back
    return (0, 0)


def _delta(d):
    from objects.geometry.delta import Delta
    return Delta(*d)


def scope_(prev, action, nxt, ctx):
    s = common_skip(prev, nxt, ctx)
    if s:
        return s
    if action == "ACTION5":
        return "换一盘（归 switch_restarts_round）"
    if action == "RESET":
        return "RESET（归 reset_restores_start）"
    if prev.walker is None:
        return "场上没有环"
    if ctx.get("hist") is None:
        return "这一关的历史不全"
    if prev.me != nxt.me and choice(prev, ctx["hist"].walker_heading()) is None:
        return "环在岔路口"
    return None


def assert_(prev, action, nxt, ctx):
    if prev.me == nxt.me:
        return nxt.walker == prev.walker
    d = choice(prev, ctx["hist"].walker_heading())
    want = prev.walker + _delta(d)
    if want in {c.cell for c in nxt.carts}:
        return nxt.walker is None
    return nxt.walker == want
