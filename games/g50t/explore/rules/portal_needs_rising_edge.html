它说什么

走进传送门：同一张网上有按钮在这一步被压下（上升沿）就传到搭档那扇门，否则停在门里。按住不放不算。

论域：只管 ACTION1..4 且目标格是一扇进得去的传送门。那张网上的门不恰好两扇 → 不管（配不出搭档）。压按钮的可以是棋子以外的活物（替身、环）——同一步里别人压下的也算。

它明确不主张什么

不说门开着能持续几步（语料里只见过同一步内的上升沿；「压下后开若干步」这种读法没被分开过）。

改版史

  • 起点册子 portal_teleport v4 与 portal_pairing v2 是同一条规则的两个时期（先按「同色恰好两扇」配对，后改按轨道网配对）。合成一条，按轨道网配对；portal_teleport 的论域是 portal_pairing 的子集。
  • 上升沿的「压着」按格读（活物压着那一格），不再按像素认按钮形状——按钮被压住时 3×3 整块被盖掉，按形状认会让被压的按钮永远读成没人压（起点册子里 pressed_colors 的那个老坑）。
  • 接线（哪几个按钮开这一对门）改从开局那一帧读：解析改成「活物底下照中心孔记地板」之后，当帧被压着的按钮不在网上了——突变体「按住也算传」随之一次都不红（反向测试那一行由红变没红）。同一个老坑换了个入口：被压着的按钮看不见。

def scope_(prev, action, nxt, ctx):
    s = common_skip(prev, nxt, ctx)
    if s:
        return s
    if action not in MOVE_ACTIONS:
        return "不是方向键"
    t = target(prev, action)
    if prev.at(t) not in ("A", "B", "F"):
        return "目标格不是传送门（归 me_steps_if_free）"
    if not enterable(prev, t):
        return "门被车堵着"
    if ctx.get("hist") is None:
        return "这一关的历史不全"
    if portal_link(ctx["hist"].start(prev), t) is None:
        return "那张网上的门不恰好两扇"
    return None


def assert_(prev, action, nxt, ctx):
    # 接线从**开局那一帧**读：被压着的按钮在当帧只露出中心孔（读成地板），当帧的网上就少了它——
    # 实测这样读时，「按住也算」的突变体一次都红不了（被压着的按钮正是它要分辨的那一种）。
    t = target(prev, action)
    other, buttons = portal_link(ctx["hist"].start(prev), t)
    want = other if rising(occupied(prev), occupied(nxt), buttons) else t
    return nxt.me == want
