它说什么

RESET：下一帧 = 这一关开局那一帧（棋子 / 环 / 车 / 游标 / 计数条都回去，替身清空）。

论域：只管 RESET，且 RESET 前后是同一关、两帧都读得成世界（换卡那一次的 RESET 前一帧是收场画面，读不成，不管）。 为什么不进模型：「这一关的开局长什么样」不是当前状态的函数，它是历史——一帧上读不出来。硬塞一个「开局」字段进世界，就是给模型加一位帧上读不出来的信息。所以它写成一条明处的假设：形式化那一层每一段逐帧核对都从开局起算，这条假设要是错的，重来之后那一段的第一帧就对不上——那是它在语料上唯一一次被驳倒的机会。

它明确不主张什么

不说 RESET 之后「之前录的带子」还在不在（游标回 0、替身清空，看上去是没了；这一条只说看得见的那部分）。

def scope_(prev, action, nxt, ctx):
    s = common_skip(prev, nxt, ctx)
    if s:
        return s
    if action != "RESET":
        return "不是 RESET"
    if ctx.get("hist") is None:
        return "这一关的历史不全"
    return None


def assert_(prev, action, nxt, ctx):
    w0 = ctx["hist"].start(prev)
    return (nxt.me == w0.me and nxt.walker == w0.walker and nxt.carts == w0.carts
            and not nxt.ghosts and nxt.hud == w0.hud and nxt.spent == 0)
