# goal_is_levelup（`rule/什么算赢/goal_is_levelup.py`）—— **定义**

「赢」是一个**状态**性质：棋子站在终点格上。不是一个转移事件——
写成事件的话没有任何一个状态是目标，「这个局面走不走得通」就无从问起。
走进终点格的那一步由 `meStepsIfFree` 管（终点格进得去），走进去之后这个状态就是赢。
-/

def scope_(prev, action, nxt, ctx):
    if prev is None:
        return "读不成世界"
    if action not in MOVE_ACTIONS:
        return "不是方向键"
    if ctx.get("level_prev") is None or ctx.get("level_next") is None:
        return "ctx 缺关卡号"
    return None


def assert_(prev, action, nxt, ctx):
    t = target(prev, action)
    hit = prev.at(t) == GOAL and enterable(prev, t)
    up = ctx["level_next"] == ctx["level_prev"] + 1
    same = ctx["level_next"] == ctx["level_prev"]
    return up if hit else same
