形式化

对象 / 规则 / 分发全是定义；要证的只有「这一关走得通」。
这是个什么游戏回放对象规则形式化怎么给别人看

明写的缺口（摆在最上面，没藏）

  • 逐条那一层（每条转移从观测到的那一帧重新起算）没有建：每段都从开局起全程自算（比逐条严），认证段 280 步 + 未认证段 512 步；断点（过关 / RESET / 收场）那几步不在任何一段里，它们只在 Python 规则层被核
  • 走不通的钥匙一把都没有：七关都有真人走通的见证，没有一关要宣告不可做；Reachable.lean 里只有骨架（unsolvable_of_invariant）与 not_both，没有挂上任何局面
