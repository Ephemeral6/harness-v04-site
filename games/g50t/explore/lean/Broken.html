# Broken.lean —— **这一份应当编不过**，而且只在标记那一行红

一套证明如果什么都证得出来，那它一条也没证。所以这里故意写一句**和现有主张正面冲突**的话：

    第 0 关开局，往右走一步就赢了。

它和 `Proof/Levels/L0.lean` 冲突：那一关真人走了 17 下才进终点格，终点格在右下角，
起点往右一格是地板不是终点。`decide +kernel` 会当场算出这一句是假的。

验收（`verify.py`）要两句都成立：**编不过**，而且**错误只落在标记的那一行**。
错误落在别处 = 红的是笔误，不是这条主张；错误 0 处 = 这套证明测不出错。
-/
import Proof.Levels.L0
