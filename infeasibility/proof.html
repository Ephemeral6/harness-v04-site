inv-A · formal/InvA.lean

在这份世界实现里无解：不限步数，任何一串移动都到不了终局。 每一步移动都不改变一个奇偶量 Φ（去掉空格后，数字序列里逆序对个数的奇偶）。开局 Φ = 1，终局 Φ = 0，所以没有任何一串移动能从开局走到终局。

InvA.not_solvable公理：propext、Quot.sound
/-- **inv-A 的证书**：从 start 出发，任何动作序列都到不了 goal。 -/
theorem not_solvable : ¬ ∃ route : List Dir, run start route = goal := by
  intro ⟨route, h⟩
  have hs : start ∈ allBoards := List.contains_iff_mem.mp start_mem
  have ⟨_, hp⟩ := run_keeps hs route
  rw [h] at hp
  exact phi_start_ne_goal hp.symm

BudB.not_solvable_within公理：propext、Quot.sound
/-- **bud-B 的证书**：预算 `B` 是陈述的参数。`B < 21` 时，任何 ≤ B 步的路线都到不了 goal。

theorem not_solvable_within (B : Nat) (hB : B < 21) :
    ¬ ∃ route : List Dir, route.length ≤ B ∧ run start route = goal := by
  intro ⟨route, hlen, hrun⟩

  rw [hrun, dist_goal, dist_start] at hd        -- 21 ≤ 0 + route.length

适用范围

证书讲的是哪个世界

每条「无解」定理的对象，是 Lean 文件里的 step 与 run。它们是作者照着 Python 世界实现手写的形式化，不是从观测里归纳出来的。所以准确的说法是：在这份世界实现（及其 Lean 形式化）里无解。这条结论我们不撤——在这个模型里，它是内核核过的定理。它能不能推到别的实现上，取决于那份实现与这里的 step 是否一致：C6 上逐条全量比过（2880/2880），C7 上只采样比过（24072 条）。

如果模型是从交互里归纳出来的，它只包含见过的转移，是从下逼近真实世界；而「无解」只有在模型从上逼近（一条可能的转移都没漏）时，才能传给真实世界。所以对归纳出的模型，能说的是「在归纳出的模型里无解」，本页的定理也按这个口径读。

C7 的采样差分覆盖不到被否定的那一侧

判据 5 的 6018 个样本盘面全部是从终局出发游走、再加上各实例的路线得到的。按 Φ 分，Φ=0 的有 6017 个，Φ=1 的只有 1 个（就是 inv-H 的开局本身）。inv-H 的定理讲的恰恰是 Φ=1 那一侧的全部盘面，所以采样差分对它几乎没有提供经验支持。独立审计还构造了一个反例：一个与全部样本转移都一致、但加了一条局部规则的 step'，在它下面 inv-H 有路线可走（exp/2026-09-25-audit/CounterStep.lean 重编 rc=0，solvable' 的公理读数：propext）。这不影响「在模型里无解」，但它说明：不能把 C7 的采样差分读成「定理所涉的那部分世界有经验支持」。

C7 难在尺寸，不在结构

奇数宽滑块拼图的可达性完全由这个奇偶量决定，是教科书结果；预算实例的下界就是曼哈顿距离，同样是教科书内容。审计用四条不做任何搜索的浅规则判 C7 的六局（只看作答方拿到的题面），得分分别是 R_textbook 6/6、R_hb 6/6、R_twin 6/6、R_hamming 6/6。也就是说，C7 对「靠搜索找路线」的解题方难，是因为状态空间大；它考不出解题方能不能发现一个陌生的不变量。

theorem all_mem {α} {p : α → Bool} {l : List α} (h : l.all p = true) {x : α} (hx : x ∈ l) :
    p x = true := by
  induction l with
  | nil => cases hx
  | cons y ys ih =>
      simp only [List.all_cons, Bool.and_eq_true] at h
      cases hx with
      | head => exact h.1
      | tail _ hm => exact ih h.2 hm

  cases d <;> simp [dirs]

  have h1 := all_mem phi_invariant_all hb
  have h2 := all_mem h1 (dirs_complete d)
  exact (beq_iff_eq).mp h2

theorem step_keeps_mem {b : Board} (hb : b ∈ allBoards) (d : Dir) : step b d ∈ allBoards := by
  have h1 := all_mem closed_all hb
  have h2 := all_mem h1 (dirs_complete d)
  exact List.contains_iff_mem.mp h2

    ∀ route : List Dir, run s route ∈ allBoards ∧ Phi (run s route) = Phi s := by
  intro route
  induction route generalizing s with
  | nil => exact ⟨hs, rfl⟩
  | cons a as ih =>
      have hm := step_keeps_mem hs a
      have hp := step_keeps_phi hs a
      obtain ⟨m, p⟩ := ih hm
      exact ⟨m, p.trans hp⟩

  have ⟨_, hp⟩ := run_keeps hs route
  rw [h] at hp
  exact phi_start_ne_goal hp.symm

theorem inv_swap : ∀ (A : List Nat) (x y : Nat) (B : List Nat),

  induction A with
  | nil => intro x y B; simp only [List.nil_append, inv, cnt]; omega
